# Claude project guidance

Before substantive project work, read and follow:

- `AGENTS.md` for repository context, constraints, and safety rules.
- `DEVELOPMENT_PROTOCOL.md` for shared working principles.
- `PROJECT_STYLE.md` for project-specific tone, expression, and output preferences.
- `AGENT_HARNESS.md` for task start, focused verification, and handoff.
- `AUDIT_FLEET.md` for the seven audit roles and their triggers.
- `MONITOR_REVIEW.md` for the earlier single-role design monitor.

Keep product requirements, design decisions, and progress in their respective
project documents rather than treating these guidance files as specifications.
