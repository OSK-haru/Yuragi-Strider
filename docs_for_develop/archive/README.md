# Archived project records

These documents are retained for implementation history and audit traceability.
They are not current requirements, runtime instructions, or the recommended
reading path for contributors. Start with [`../README.md`](../README.md) and
follow its canonical-document links.

## Historical phase plans

The original plans below describe completed phases, obsolete Streamlit-era
behavior, or a superseded model boundary:

- Phase 3–7.8 feature plans and the Phase 8 test plan.
- Phase 1–2 core/API plans.
- The BA-0 pulse contract, whose 501 boundary was replaced by the implemented
  endpoint in BA-6.
- The Quanscope circuit-editor plan, superseded by the React Circuit Studio.

The original filenames are preserved so old references remain recognizable.
