# Pulse 回路スタジオ

[Pulse IDE](./index.md)の作業領域で「Pulse 回路」を選んでいるときの表示です。トランズモンごとの制御レーンにPulseを並べ、**個々の波形を編集します**。編集しただけでは計算は走りません。実行はツールバーから行います([Pulseラボ](./pulse-lab.md))。

:::note[Gate-aware回路とは別物です]
ここで組むシーケンスは、Gate-awareの[回路エディター](../gate-aware/circuit-studio.md)の回路とは状態を共有しません。ゲートを並べているのではなく、**マイクロ波の波形を時間順に並べています**。
:::

## 現行バックエンドの範囲

画面上部に次の注意が常に表示されます。

> 2〜4台では Pulse Lab から全レーンを同時実行できます(交換結合ありのネットワーク)。5〜8台は回路編集のみ対応です。

5台以上を選ぶと、この帯は警告色に変わり「密度行列の計算量上限により、5台以上は回路編集のみで実行できません。実行するには4台以下にしてください。」に差し替わります。

トランズモン1台では選択中のレーンだけを順次実行します。2〜4台ではすべてのレーンを時刻0から並行配置し、異なるレーンで時間が重なるPulseを同時駆動として実行します。5〜8レーンはレイアウト作成・編集だけが可能です。

## システム全体の設定

「回路全体の構成」セクションでは、トランズモン数を1〜8から選べます。数を減らすと、消えるレーンに置かれていたPulseも一緒に消えます。

その右に並ぶのは**現在の設定の表示**です(デバイスプロファイル名、温度、デバイス品質、発展方式、最大駆動、AWG刻み、パルス間隔)。これらはここでは変更できません。変更は[Pulseラボ](./pulse-lab.md)の「外界環境と実行設定」で行います。

## Pulseパレット

左側のパレットからPulseを追加します。**クリックすると現在選択中のレーンの末尾へ**追加されます(追加先は見出しの下に「クリックで **q0** の末尾へ追加」と表示されます)。パレットのボタンを**ドラッグすれば、任意のレーンの任意の位置へ挿入**できます。

| ボタン | 生成されるもの |
|---|---|
| X/2 | X軸周りに +90°。回転角 π/2、位相 0 |
| X | X軸周りに +180°。回転角 π、位相 0 |
| Y/2 | Y軸周りに +90°。回転角 π/2、位相 π/2 |
| Y | Y軸周りに +180°。回転角 π、位相 π/2 |
| Custom | 現在のPulse設定をそのままコピー |
| VZ | ゼロ時間の位相フレーム更新(既定 λ = π/2) |

**X系とY系の違いは位相だけです。** 回転軸は駆動の位相で決まり、π/2ずらすとY軸周りになります。実機でも同じで、Y専用の配線があるわけではありません。

プリミティブは、波形の形・幅・離調・DRAG などを**現在のPulse設定から引き継ぎ**、回転角と位相だけを上書きします。したがって「X/2を置いたのに幅がおかしい」ときは、元の設定側を確認してください。

## Pulseタイムライン

トランズモンごとに1本のレーンが縦に並びます。レーン(またはその左端のラベル)をクリックすると選択が移り、以後の追加先がそのレーンになります。

各ブロックには通し番号・ラベル・補助情報が出ます。

- driveブロック → **そのPulseの時間幅** [μs]
- VZブロック → **そこまでの累積フレーム位相** [rad]

VZの表示が時間ではなく位相なのは、VZが時間を消費しないからです。

| 操作 | ボタン |
|---|---|
| 左へ移動 / 右へ移動 | ← / → |
| 削除 | × |
| 全レーンを空にする | すべて削除 |

初期状態では、q0のレーンに **X/2 → Y/2** が置かれています。

:::tip[ブロックを選ぶと実行対象になります]
driveブロックをクリックすると、そのPulseがPulseラボの単一Pulse設定へ反映され、レーンのトランズモン番号も一緒に渡ります。トランズモン1台のシーケンスでは選択レーンが実行対象です。2台以上では選択状態にかかわらず、全レーンのdriveが実行対象です。
:::

## Pulseブロックの編集

driveブロックを選ぶと、タイムラインの下に編集パネルが出ます。編集できるのは**このブロック固有の制御波形だけ**で、外界環境はPulseラボの共通設定のままです。

| 項目 | 内容 |
|---|---|
| 波形 | Gaussian / Square |
| 振幅の指定方法 | 回転角 / ピーク振幅 |
| 回転角 [rad] | 目標とする回転角。振幅は自動で逆算されます |
| ピーク振幅 [rad/μs] | 振幅を直接指定する場合 |
| Pulse長 [μs] | Square のとき |
| Gaussian σ [μs] / 打ち切り [σ] | Gaussian のとき。**幅 = 2 × σ × 打ち切り** |
| 位相 [rad] | 回転軸を決めます |
| 離調 [rad/μs] | 駆動周波数と遷移周波数のずれ |
| DRAG β [μs] | Gaussian かつ2準位モデル以外のときのみ |

右側に波形プレビューと、そのブロックの時間幅が表示されます。値を変えるとその場で形が変わります。

**変更は「ブロックへ保存」を押すまで確定しません。** 未保存の変更があるあいだボタンは「ブロックへ保存」と表示され、保存すると「保存済み」に変わります。取り消しボタンはないので、保存前に元へ戻したいときは別のブロックを選び直してください。

### 振幅指定の2つのモード

「回転角」は**やりたいこと**を指定するモード、「ピーク振幅」は**装置に出す量**を指定するモードです。回転角を選べば必要な振幅は自動計算されますが、その結果が最大駆動振幅の上限を超えることがあります。超えていればPulseラボの実行前検査で弾かれます。

なお、ピーク振幅モードのときだけ振幅分解能(量子化)の検査が入ります。回転角モードでは検査されません。

### DRAG について

DRAG は $\lvert 2\rangle$ へのリーケージを抑えるための補正で、$\Omega_x$ の微分に比例する成分を $\Omega_y$ 側に加えます。2準位モデルには漏れる先がないため、この項目は現れません。

$\beta$ を変えてPulseラボで実行し、「最大リーケージ $P_2$」がどう動くかを見るのが、この機能の一番分かりやすい使い方です。

#### 実例: β だけを変えてリーケージを半分にする

同じ回路・同じ環境のまま、DRAG係数 $\beta$ だけを 0.001 から 0.002 へ変えて実行した結果です。

| $\beta$ | リーケージ($\lvert 2\rangle$ の占有) | 計算部分空間に残る確率 |
|---|---|---|
| 0.001 | 10.04% | 89.96% |
| 0.002 | **5.58%** | 94.42% |

波形パラメータを1つ動かしただけで、漏れがおよそ半分になります。回路図の上に「Xゲート」を置いているだけでは、この差は見えません。

**測定条件**

| 項目 | 設定値 |
|---|---|
| 準位数 | 3準位 qutrit |
| トランズモン数 | 1 |
| 時間発展の解法 | 固定ステップRK4 |
| 観測時間 | 0.04 μs(スナップショット101点) |
| 非調和性 | −100 MHz |
| パルス列 | X/2 → Y/2(各 0.0160 μs) |
| 波形 | Gaussian(σ = 0.002 μs、打ち切り 4σ) |
| 回転角 | π/2 rad(位相 0、離調 0) |
| **DRAG係数 β** | **0.001 / 0.002(この2つだけを変更)** |
| 温度 | 50 mK |
| デバイス品質 | 0.8 |
| 磁束ノイズ | 1×10⁻⁶ Φ₀ |
| 量子ビット周波数 | 5 GHz |
| 最大 $T_1$ / $T_\phi$ | 100 μs / 100 μs |
| 準静的離調ノイズ | 無効 |
| デバイスプロファイル | 教育用デフォルト(実機校正値ではありません) |

比較しているのは駆動中のスナップショット($\beta$ = 0.001 は 0.0257 μs、$\beta$ = 0.002 は 0.0262 μs、いずれも純度 0.999)における密度行列の対角成分です。Pulse-levelでは測定を回路の一部として扱わないため、これは射影測定の結果ではなく**その時刻の量子状態そのもの**です。

$\beta$ の最適値の理論的な見積もり($\beta \approx 1/\lvert\alpha\rvert$ の由来)は[P3. 漏れとDRAG](../../learn/pulse/leakage-drag.md)を参照してください。

## Virtual Z の編集

VZブロックを選ぶと、専用の編集パネルが出ます。**時間を進めず、以後の論理位相フレームを更新します。**

- 回転角 λ [rad] を直接入力
- プリセットボタン: π/4、π/2、π、−π/2
- 「フレーム更新を保存」で確定

角度は $[-\pi, \pi)$ に正規化されて保存されます。また、Pulseラボの位相分解能の**整数倍**でなければ実行前検査で弾かれます(教育用デフォルトなら π/180 rad = 1° 刻み)。

単一qutritシーケンスでは、VZは実行時にAPIを呼ばず、密度行列に $U = \mathrm{diag}(1, e^{-i\lambda}, e^{-i2\lambda})$ を適用します。複数トランズモン・ネットワークでは、同じ更新をそのレーンの後続Pulse位相へ加算してから全スケジュールを送信します。どちらも時間は進みません。

## 次のステップ

シーケンスが組めたら、ツールバーの実行ボタンで実行します([Pulseラボ](./pulse-lab.md))。トランズモン数を1にすれば選択レーンだけを、2〜4にすれば全レーンを同時に実行します。
