# Pulse 状態エクスプローラー

[Pulse IDE](./index.md)の作業領域で「状態エクスプローラー」を選んでいるときの表示です。[Pulseラボ](./pulse-lab.md)の設定で実行した軌跡について、**状態が時間とともにどう動き、どう崩れたか**を読む画面です。シミュレーションそのものはここでは走りません。直前の実行が返した軌跡を見る場所です(「ツール箱」で選んだ追加の指標だけは、その軌跡から計算します)。

Gate-awareの[状態エクスプローラー](../gate-aware/state-explorer.md)と同じ読み方——**時刻カーソルを1本だけ共有し、指標・確率・密度行列を同じ瞬間で並べる**——をPulse-levelへ移した画面です。

:::note[Pulse-level専用]
表示されるのはPulseラボの実行結果だけです。Gate-awareの回路スナップショットはGate-awareの状態エクスプローラーに表示され、ここには読み込まれません。
:::

:::info[Bloch球はありません]
Gate-awareの状態エクスプローラーにあるBloch球は、この画面には**意図的に置いていません**。Bloch球は2準位の縮約状態を描く図です。Pulse-levelの状態は qutrit(3準位)や結合トランズモン($3^N$次元)で、計算部分空間へ縮約して球に描くと、**この画面でいちばん重要なリーケージがちょうど見えなくなります**。同じ情報は「占有確率分布」の $\lvert 2\rangle$ 成分と、密度行列の非対角成分で読めます。
:::

## 結果が表示されないとき

| 表示 | 状況 | 対処 |
|---|---|---|
| 結果なし | まだ一度もPulseを実行していない | 「Pulseラボを開く」から実行する |
| 再実行が必要 | 実行後にPulseの設定・波形・レーンを編集した | 現在の設定でもう一度実行する |

後者では結果自体は表示されたまま、上部に警告帯が出ます。Gate-aware側が回路の署名で結果の古さを判定するのと同じ仕組みで、Pulseでは**実行フォーム(モデル・環境・数値設定)・レーン上のPulse・実行ハードウェア制約**の組が指紋になります。ひとつでも変えれば「変更前の条件の数値を見ている」と表示されます。

## 時刻カーソル

この画面の中心は、全パネルが共有する**1本の物理時刻**です。

- 「物理時間」パネルの再生・スライダー・◀ ▶ で動かす
- 「占有確率」パネルのサンプル送りでも動く
- 動かすと、指標・確率遷移・密度行列の表示時刻が同時に揃う

初期位置は**Pulse終了時刻**です。Gate-awareが「回路の後」のスナップショットを初期表示にするのと同じ理由で、駆動を切った直後の状態がまず知りたい状態だからです。

## 表示項目の選び方

画面上部の「表示項目」メニューで、パネルの表示・非表示を切り替えます。「すべて表示」「すべて非表示」もここにあります。各パネルの見出しをクリックしても個別に開閉できます。

**初期状態では「指標タイムライン」と「確率比較」だけが開いています。** この選択は、Pulseラボの右にある「ツール箱」と同じものです。どちらで切り替えても、もう一方に反映されます。

### ツール箱で追加の指標を選ぶ

Pulseラボの右、環境と Pulse の設定の下にある「ツール箱」で、追加の指標を選べます。選んだものはこのページの末尾にパネルとして並びます。表示中の値から決まってしまう指標は、最初から並べていません。

| 指標 | 見るもの | 使える条件 |
|---|---|---|
| フォン・ノイマン・エントロピー | 選んだトランズモンの縮約状態の $S(\rho)$ [bit]。3準位では純度と独立な量で、複数台では残りとのもつれを表す | 3準位、または2台以上。**2準位1台は純度で決まるので使えません** |
| コンカレンス | 2準位の2台のエンタングルメント | 2準位で2台以上 |
| ネガティビティ | 選んだトランズモンと残りの間のエンタングルメント。漏れ準位を含む全空間で測る | 2台以上 |
| 相互情報量 | 2つのトランズモン集合 A, B の全相関 $I(A:B)$ | 2台以上 |
| パウリ演算子の期待値 | 計算準位 $\{0,1\}$ 上の $\langle P\rangle$。X, Y は位相の情報で、準位 2 には作用しない | 3準位、または2台以上 |

Pauli文字列は左端が q0 です。1台の $Z$ は占有数の差としてすでに表示されているので受け付けません。X か Y を含む文字列、または2台以上に作用する文字列を入れてください。

追加の指標は、保存した軌跡の**各時刻の密度行列**から計算します。シミュレーションをやり直さないので、実行後に選び直しても、読み込んだ結果ファイルに対しても使えます。ただし2準位1台のモデルは占有数しか返さず、各時刻の密度行列がないため、この区分の指標はすべて使えません。

:::note[Gate-awareのツール箱との違い]
理想状態とのトレース距離、プロセスの評価(平均ゲート忠実度・χ 行列)、T1 / Ramsey スイープは、Pulse側にはまだありません。Pulseには「理想の軌跡」を返す経路が2準位にしかなく、目標ゲートの定義も結合モデルでは決まっていないためです。
:::

## 各パネル

### 物理時間

パルス列を実時間の軸に並べ、再生しながら状態の変化を追うパネルです。帯は駆動区間・アイドル区間・仮想Zの瞬間に分かれ、シーケンス実行ではブロックのラベルが各区間に出ます。

Gate-awareの同名パネルが回路の列を実時間に並べるのに対し、こちらが並べるのは**波形の区間**です。仮想Zは時間を消費しないため、幅を持たない印として表示されます。

読み取り欄には、現在の区間・サンプル番号・Pulse終了時刻・その時刻の純度が出ます。

:::tip[動きを抑える設定のとき]
設定メニューでアニメーションを切っている場合、自動再生は無効になります。スライダーと ◀ ▶ で時刻を動かしてください。
:::

### 指標タイムライン

Gate-awareの指標タイムラインに対応するパネルです。時間の関数として次を重ねます。

| 系列 | 意味 |
|---|---|
| 純度 | $\mathrm{Tr}(\rho^2)$。環境と混ざるほど1から下がる |
| 目標状態との重なり / 閉じた系への忠実度 | qutrit単発では目標状態との重なり、2準位では散逸を切った閉じた系との忠実度 |
| リーケージ | 計算部分空間の外にある確率。qutritでは $P_2$、結合モデルでは計算基底以外の総和 |
| 区間状態変化 | 隣り合うサンプル間の密度行列の Hilbert–Schmidt 距離 |

Gate-awareでは「忠実度・純度がノイズの劣化を、区間状態変化がゲートによる状態の移動を表す」という読み方をしました。Pulseでも同じで、**区間状態変化が大きい区間ほど、波形が状態を回している区間**です。破線が立っていないのに純度が落ちていれば、それは駆動ではなく環境による劣化です。

縦の点線 `PULSE END` が駆動の終わりです。その右側は、駆動を切ったあとの環境だけによる発展です。

要約カードには、Pulse終了時と最終時刻の純度、参照値の最終値、最大リーケージ、最大区間状態変化、カーソル時刻の純度が並びます。

:::note[結合モデルに参照値はありません]
トランズモン・ネットワーク(2台以上)では、参照する目標状態を単一の解析解として定義していないため、重なり・忠実度の系列は表示されません。純度とリーケージだけが指標になります。1台でのシーケンス実行でも、合成先を単一の目標状態として定義していないため同じく N/A です。
:::

### 占有数タイムライン

Pulseラボの結果にもある「占有確率と品質指標」のグラフを、時刻カーソル付きで表示します。準位ごと(または基底ごと)の占有確率を全部まとめて俯瞰したいときはこちらです。

### 確率比較

Gate-awareの「確率遷移：理想 vs ノイズあり」に対応するパネルです。基底状態をひとつ選び、その占有確率の時間変化を描きます。

**2準位モデルでは、散逸を切った閉じた系の軌道が重なります。** 2本の差がそのまま環境の寄与です。qutritと結合モデルではAPIが対応する閉じた系の軌道を返さないため、開いた系の1本だけを描きます。

下部には、カーソル時刻での開いた系の値・閉じた系の値・その差が出ます。

### 占有確率

カーソル時刻の占有確率分布です。Gate-awareの「出力確率」に対応しますが、**Pulse-levelでは測定を回路の一部として扱わないため、これは射影測定の結果ではなく密度行列の対角成分そのもの**です。

計算部分空間の外にある基底は色を変えて表示され、上部に「計算部分空間の合計」と「計算空間外の確率」が並びます。基底が13個以上のモデル(ネットワークなど)では、既定で確率の大きい上位12基底だけを表示し、ボタンで全基底に切り替えられます。

サンプル送りのスライダーは他のパネルと同じ時刻カーソルを動かします。

### 密度行列

カーソル時刻の完全な密度行列 $\rho$ です。対角が占有確率、非対角がコヒーレンスです。1台なら準位数そのもの(2×2 または 3×3)、2台以上なら $L^N\times L^N$(最大 81×81)になります。

大きい行列では「行列要素を検索」を使います。行・列に基底ラベル(例: `010`)または `#要素番号`(例: `#7`)を入力し、周辺幅±1〜±3を選ぶと、そのセルと周辺だけが表示されます。

:::note[2準位モデルの密度行列は2点だけ]
2準位ベースラインの軌跡は占有確率のみを返し、密度行列はPulse終了時と最終時刻でしか得られません。このためこのパネルは最終時刻の密度行列を表示し、カーソルには追随しません。カーソルに合わせて動く密度行列が必要なら、qutrit以上のモデルを選んでください。同じ理由で、2準位では指標タイムラインの「区間状態変化」も表示されません。
:::

## 前回の実行と見比べる

Gate-awareの[状態エクスプローラー](../gate-aware/state-explorer.md#前回の実行と見比べる)と同じ仕組みが、この画面にもあります。「表示項目」メニューの下の帯で、いまの結果を保持し、次の実行と重ねて読めます。

保持できるのは**1件・画面全体で1つ**です。時刻カーソルを1本だけ共有する設計のため、パネルごとに別の実行を保持できると、隣り合う図が別々の条件を指してしまいます。

### 重ねられるのは「環境だけを変えた実行」です

2本の差を環境の寄与として読むには、駆動と観測条件が同じでなければなりません。そのため保持した時点の

- 状態空間(モデル・準位数)
- 駆動(波形・振幅・幅・位相・離調・DRAG・非調和性・ネットワーク結合)
- 観測条件(総観測時間・スナップショット数)
- 回路(トランズモン数・全レーンの操作列)

を指紋として覚えておき、**現在の設定と一致しなくなった時点で保持を自動的に破棄します**。環境モード・デバイス品質・温度・$T_1$・$T_\phi$・各 $\gamma$・準静的ノイズは指紋に含めないので、これらを変えて再実行しても保持は残ります。

### 重ねる線は常に1本だけです

比較線が出るのは「**指標タイムライン**」と「**確率比較**」の2枚だけです。指標タイムラインは純度・参照値・リーケージ・区間状態変化がすでに走っているため、**どの指標を重ねるかを凡例のプルダウンで選びます**。モデルによって返らない指標は選択肢に出ません(2準位ではリーケージ、シーケンス実行では参照値など)。

環境パラメタの変化が小さいと2本がほとんど重なります。その場合は差が線幅に埋もれている旨が図の上に表示されます。

## 結果を書き出す

同じ帯の右端に「**結果を書き出す**」があります。表示中の実行を、**それを生んだ入力ごと** JSON ファイルとして保存します。

ファイル名は `pulse結果_YYYYMMDD-HHMMSS.json` です。時刻は書き出した時刻ではなく**実行した時刻**なので、複数のファイルを並べたときにどの実行かが名前で分かります。

| キー | 内容 |
|---|---|
| `meta` | 書き出した時刻(ISO 8601)と生成元 |
| `inputs.pulse_circuit` | その結果を計算したパルス回路(トランズモン数・全レーンの操作列) |
| `inputs.lab_form` | **実行時点の**Pulseラボ設定。実行後に画面で変えた値ではありません |
| `run.completed_at` | 実行が完了した時刻 |
| `run.signature` | 実行条件の指紋。同じ値なら同じ条件で計算されています |
| `result` | 応答そのもの(軌跡、リーケージ、診断、警告、制限事項) |

`run.signature` を入れているのは、**2つのファイルが同じ条件のものかを目で照合できる**ようにするためです。この値が一致していれば、差は条件の違いではありません。

`inputs.lab_form` が実行時点の値である点は重要です。実行後にPulseラボへ戻ってパラメータを触っても、書き出されるのは**その結果を実際に生んだ設定**です。

## 結果を読み込む

書き出したファイルは、同じ帯の「**結果を読み込む**」から読み戻せます。まだ一度も実行していない状態（「結果がありません」の画面）にも同じボタンがあるので、**人から受け取ったファイルをそのまま開けます**。

読み込むと、次の3つが**同時に**復元されます。

| 復元されるもの | どこへ入るか |
|---|---|
| 結果 | Pulse 状態エクスプローラーの各パネル |
| パルス回路 | [Pulse 回路スタジオ](./pulse-circuit-studio.md)の編集中の回路 |
| ラボ設定（実行時点のもの） | [Pulseラボ](./pulse-lab.md)の入力欄 |

### なぜ回路と設定まで一緒に戻すのか

この画面は、実行時の設定の指紋（`signature`）が現在の設定と一致するかを毎回照合し、**食い違えば「再実行が必要」として結果を隠します**。

そのため結果だけを読み込んでも、指紋が現在の設定と合わず、復元した結果はその場で隠れてしまいます。読み込みが回路とラボ設定を戻すのは、この照合を通すためです。結果とその入力をセットで復元することで、読み込んだあとも「画面の設定 = 図の条件」が成り立ちます。

:::warning[読み込むと現在の回路と設定は置き換わります]
結果の読み込みは、編集中のパルス回路とラボ設定を上書きします。保持していた比較も破棄されます（読み込んだ結果は別条件のものなので、重ねて読める保証がないためです）。
:::

### 読み込んだ結果には印が付きます

読み込んだ結果を表示しているあいだ、パネルの上に**「読み込んだ結果を表示しています」**と出ます。

計算し直した結果と見分けが付かないと、**その数字がいまの設定で得られたものだと誤解される**ためです。この印が消えるのは、実際にPulseラボで再実行したときだけです。

### 読み込めないファイル

次のものは、図を描く前に弾かれます。

| 弾かれるもの | 理由 |
|---|---|
| Gate-awareの結果ファイル | モードが違います。[Gate-aware 状態エクスプローラー](../gate-aware/state-explorer.md#結果を読み込む)から開いてください |
| Yuragi-Strider以外のJSON | 結果ファイルではありません |
| 将来のバージョンのファイル | 黙って誤読するより、読めないと言うほうが安全です |
| `run.signature` を含まない結果 | 現在の設定と同条件かを照合できません |

読み込んだ記録の `signature` は、**ファイルに入っていた実行時のものをそのまま使います**。読み込み側で作り直すと、書き出した実行と同じ条件かどうかを照合できなくなるためです。

## 画面下部の要約

モデル名・トランズモン数・密度行列の次元・サンプル数・総観測時間が表示されます。シーケンス実行では操作数も出ます。サンプル数はPulseラボの「スナップショット数」で決まります。

## Gate-awareとの対応

| Gate-aware 状態エクスプローラー | Pulse 状態エクスプローラー |
|---|---|
| 物理時間(回路の列を実時間に並べる) | 物理時間(駆動・アイドル・仮想Zの区間を並べる) |
| 指標タイムライン(忠実度・純度・区間状態変化) | 指標タイムライン(純度・参照値・**リーケージ**・区間状態変化) |
| 確率比較(理想 vs ノイズあり) | 確率比較(閉じた系 vs 開いた系。2準位のみ2本) |
| 出力確率(測定の確率分布) | 占有確率(密度行列の対角成分) |
| Bloch球 | **なし**(縮約するとリーケージが隠れるため) |
| 密度行列(理想と並べて表示) | 密度行列(カーソル時刻の $\rho$) |
| Message → Receive | なし(Pulseに論理的な状態転送の概念がないため) |
