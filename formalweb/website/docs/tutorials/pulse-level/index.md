# Pulse-level ワークスペース

Pulse-levelモードは、ゲートより下の層を扱います。「Xゲートをかける」ではなく、**どんな形のマイクロ波をどれだけの時間当てるか**を指定し、トランズモンがどう応答するかを直接追うワークスペースです。モデルの中身は[Pulse-levelモデル](../../physics-model/control_models/pulse-levelmodel.md)を参照してください。

:::warning[実験的な機能です]
Pulse-levelは回転フレーム・RWA(回転波近似)に基づく実験的モデルであり、**校正済みのハードウェアモデルではありません**。デバイスプロファイルの制約値も実機の校正値ではなく、学習用の仮想デバイスです。
:::

## Pulse IDE(`/pulse-ide`)

Pulseモードの操作は、すべて**1つのIDE画面**の中で行います。配置は[Gate-awareのIDE画面](../gate-aware/index.md)と同じで、ペインの開閉と境界線のドラッグも同じように使えます。

```text
┌ タイトル行   [Pulse 回路] [状態エクスプローラー]        表示 ▸ ナビゲーター / プロパティ / メッセージ ┐
├ ツールバー   [q0 シーケンスのみ実行 など]                         いま何を実行するかの1行 ┤
├──────────────┬────────────────────────────────┬───────────────────────┤
│ ナビゲーター │ 作業領域                       │ プロパティ            │
│  構成の要約  │  Pulse 回路スタジオ            │  環境と Pulse の設定  │
│              │   または Pulse 状態エクスプローラー │ (Pulseラボの設定)    │
├──────────────┴────────────────────────────────┴───────────────────────┤
│ メッセージ   [実行] [波形] [結果]                                                │
└ ステータスバー  準備完了 · 準位数と台数 · Pulse 時間幅 · 最終実行 ───────────────────┘
```

| 場所 | 中身 | 説明 |
|---|---|---|
| 作業領域(Pulse 回路) | レーンへのPulseの配置と波形の編集 | [Pulse 回路スタジオ](./pulse-circuit-studio.md) |
| プロパティ、ツールバー、メッセージ | 量子系モデル・外界環境・ハードウェア制約、実行、計算量の見積もり、駆動波形 | [Pulseラボ](./pulse-lab.md) |
| 作業領域(状態エクスプローラー) | 実行済み軌跡の読み解き | [Pulse 状態エクスプローラー](./pulse-state-explorer.md) |
| ナビゲーター | トランズモン数・準位数・実行対象・密度行列の次元・Pulse 時間幅・総観測時間 | ― |

以前の `/pulse-lab`・`/pulse-circuit-studio` を開くと Pulse 回路の表示で、`/pulse-state-explorer` を開くと状態エクスプローラーの表示で、このIDE画面に移ります。

## 役割分担に注意

Gate-awareのIDE画面とは、設定と実行の分担が違います。

```text
Pulse 回路スタジオ ── 各Pulseの波形（形・振幅・幅・位相・離調・DRAG）
                    └ シーケンスの並び

Pulseラボ ────────── 量子系モデル（準位数 2/3 × トランズモン数 1〜4）
                    ├ 外界環境（温度・T1・Tφ、または Lindblad率）
                    ├ 実行ハードウェア制約（AWG周期・分解能・上限）
                    ├ 実行
                    └ 結果の要点（波形・占有確率・最終密度行列）

Pulse 状態エクスプローラー ── 実行済み軌跡の読み解き
                    ├ 全パネル共通の時刻カーソル
                    ├ 指標タイムライン（純度・参照値・リーケージ・区間状態変化）
                    ├ 確率比較 / 占有確率分布
                    └ カーソル時刻の密度行列
```

**波形はPulse回路スタジオでしか編集できず、実行はPulseラボでしかできません。状態エクスプローラーは計算をしません。** トランズモン1台では選択レーンが実行対象です。2台以上では全レーンのスケジュールが渡され、同時駆動を含めて実行されます。

環境設定(温度・T1など)は**シーケンス内のすべてのブロックに共通**で適用されます。ブロックごとに温度を変えることはできません。

## 標準的な流れ

```text
ホーム → PULSEモードを開始 → Pulse IDE
          ↓
        右のプロパティ（モデルと環境を確認）
          ↓
        作業領域の Pulse 回路（Pulseを並べる・波形を調整する）
          ↓
        ツールバーの実行ボタン（メッセージで見積もりと波形を確認）
          ↓
        作業領域を状態エクスプローラーに切り替え（軌跡を時刻ごとに読み解く）
```

初期状態では、q0のレーンに **X/2 → Y/2** の2つのPulseが最初から置かれています。まず何も変えずにツールバーの実行ボタンを押し、状態エクスプローラーで占有確率が動くのを確認するのが最短です。

## Gate-awareとの関係

2つのモードは**状態を共有しません**。Pulseの結果はGate-awareの[状態エクスプローラー](../gate-aware/state-explorer.md)には現れず(Pulse専用の[Pulse 状態エクスプローラー](./pulse-state-explorer.md)で読みます)、Gate-awareの回路はPulse側の実行対象になりません。ナビゲーションメニューではモードごとにまとまって並んでいます。

状態エクスプローラーが2つあるのは、見るべき量が違うからです。Gate-aware側は理想回路とのズレとBloch球上の縮約状態を見る画面、Pulse側は**リーケージを含む多準位の占有と、駆動区間ごとの状態の動き**を見る画面です。詳しい対応表は[Pulse 状態エクスプローラー](./pulse-state-explorer.md#gate-awareとの対応)にあります。
