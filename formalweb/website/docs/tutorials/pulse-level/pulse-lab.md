# Pulseラボ(設定と実行)

[Pulse IDE](./index.md)のうち、**量子系モデル・外界環境・ハードウェア制約を決めて実行する**部分の説明です。設定は右のプロパティ欄「環境と Pulse の設定」、実行はツールバー、計算量の見積もりと駆動波形は下のメッセージ欄にあります。個々のPulseの波形は作業領域の[Pulse 回路スタジオ](./pulse-circuit-studio.md)で編集します。

:::warning[校正済みモデルではありません]
回転フレーム・RWAに基づく実験的モデルです。特定の実機を再現するものではありません。
:::

## いま何を実行するか

ツールバーの右側に、いま何を実行しようとしているかの1行が出ます。実行ボタンの文言も、これに合わせて変わります。

| 表示 | 状況 |
|---|---|
| 単一Pulse実験 | トランズモン1台 + Pulse回路にブロックがない。現在の単一Pulse設定を実行します |
| q0 シーケンス実行 | トランズモン1台(3準位) + 回路にブロックあり。**密度行列と共通環境を引き継いで順番に実行します** |
| 複数レーン同時実行 | トランズモン2〜4台。全レーンを1本の時間軸で同時に実行します |

### 詳細モードで出る識別情報

左のナビゲーターには、トランズモン数・準位数・実行対象・密度行列の次元・Pulse 時間幅・総観測時間が常に出ます。[設定メニュー](../index.md#設定メニュー)の**詳細モード**をONにすると、その下に次の項目も表示されます。

| 項目 | 内容 |
|---|---|
| モデル | 2準位ベースライン / 3準位トランズモン qutrit / $N$トランズモン・ネットワーク($L^N$準位) |
| フレーム | 回転フレーム / RWA |
| 発展方式 | 固定ステップ RK4 / 明示的 CPTP 写像 |

発展方式は、プロパティ欄の「時間発展の解法」欄からも読み取れます。

## 外界環境と実行設定

プロパティ欄の設定は、**Pulse回路内のすべてのブロックに共通で適用されます**。

### 量子系モデル

量子系モデルは**準位数と台数の2軸**で決まります。名前のついたモデルを選ぶのではなく、この2つを動かして構成します。

| 軸 | 選択肢 | 意味 |
|---|---|---|
| 準位数 $L$ | 2準位(軽量・漏れなし) / 3準位 qutrit(漏れ準位あり) | 各トランズモンを何準位で打ち切るか。3準位では **$\lvert 2\rangle$ への漏れ(リーケージ)が見えます**。既定は3準位 |
| トランズモン数 $N$ | 1 / 2 / 3 / 4 | 同時に発展させるトランズモンの台数。2台以上で隣接ペアに交換結合 $J(a_i^\dagger a_j + a_i a_j^\dagger)$ が入ります |

密度行列の次元は $L^N$ です。組み合わせと実行内容の対応は次のとおりです。

| $L$ | $N$ | 次元 | 実行内容 |
|---|---|---|---|
| 2 | 1 | 2 | 最も単純なベースライン。リーケージという概念がありません |
| 3 | 1 | 3 | 3準位で打ち切った単一トランズモン。回路にブロックがあればシーケンス実行になります |
| 2 | 2〜4 | 4〜16 | 結合ありのネットワークを2準位で。$3^N$ より軽く、台数を増やしたいときの逃げ道です |
| 3 | 2〜4 | 9〜81 | 結合ありのネットワークを3準位で。リーケージを含む最もリアルな構成 |

トランズモン数は Pulse Lab の環境パネルからも、[Pulse 回路スタジオ](./pulse-circuit-studio.md)からも変更できます(同じ値を共有しています)。1台なら現在の単一Pulse設定またはレーンのシーケンスを、2台以上ならCircuit Studioの全レーンを同じ時間軸で実行します。

:::note
以前は「2準位モデル / Qutrit / 2トランズモン結合(9次元) / 複数トランズモン・ネットワーク」という4つの名前つきモデルを選ぶ形でしたが、これらはすべて上の2軸に統合されました。旧「2トランズモン結合(9次元)」は **3準位 × 2台** と同じ構成です。
:::

### 環境入力

| 選択肢 | 入力する値 |
|---|---|
| 物理パラメータ | デバイス品質・温度 [mK]・磁束ノイズ [$\Phi_0$]・量子ビット周波数 [GHz]・最大 $T_1$ [μs]・最大 $T_\varphi$ [μs] |
| Lindblad率を直接指定 | 緩和率そのもの [1/μs] |

「Lindblad率を直接指定」を選ぶと、温度などを経由せずに率を直接与えられます。トランズモン系では準位間ごとに指定します($\gamma_{10}^{\downarrow}$、$\gamma_{01}^{\uparrow}$、$\gamma_{21}^{\downarrow}$、$\gamma_{12}^{\uparrow}$、隣接準位の位相緩和)。2準位モデルでは3つ(down / up / φ)です。

物理パラメータ側の既定値は、Gate-awareの[シミュレーションワークスペース](../gate-aware/simulate.md)と同じ(品質0.8、15 mK、$10^{-6}\,\Phi_0$、5 GHz、$T_1$/$T_\varphi$ 各100 μs)です。同じ環境でゲート層とパルス層を比べられるようにしてあります。

### 共通の数値設定

| 項目 | 既定値 | 意味 |
|---|---|---|
| 観測時間 [μs] | 0.02 | Pulse終了後の待機も含む総時間 |
| スナップショット数 | 101 | 2〜1001。軌跡の記録点数 |
| 非調和性 [MHz] | −100 | 0以下。$\lvert 1\rangle\!-\!\lvert 2\rangle$ 遷移が $\lvert 0\rangle\!-\!\lvert 1\rangle$ からどれだけずれているか |

**非調和性はリーケージの起こりやすさを直接決めます。** 絶対値を小さくすると準位間隔が近づき、$\lvert 2\rangle$ への漏れが増えます。

### 実行ハードウェア制約

現実の装置が持つ制約を模したセクションです。デバイスプロファイルを選ぶと7項目がまとめて切り替わります。

| プロファイル | 最大駆動振幅 | 最小パルス幅 | AWG周期 | 位相分解能 | 最大離調 | パルス間待機 |
|---|---|---|---|---|---|---|
| 教育用デフォルト | 1000 rad/μs | 0.004 μs | 0.0005 μs | π/180 rad | 500 rad/μs | 0.001 μs |
| 標準トランズモンAWG | 250 rad/μs | 0.008 μs | 0.001 μs | π/180 rad | 100 rad/μs | 0.004 μs |
| 高帯域AWG | 1500 rad/μs | 0.002 μs | 0.00025 μs | π/360 rad | 1000 rad/μs | 0.0005 μs |

個別に値を変えると、表示は「カスタム」になります。**これらは実機校正値ではありません。**

制約は実行前に検査され、違反しているとエラーとして列挙されて実行できません。

| 検査 | 内容 |
|---|---|
| 最小パルス幅 | Pulse幅が下限以上か |
| AWG周期 | Pulse幅がAWGサンプル周期の**整数倍**か |
| 位相分解能 | 位相とVirtual Zの角度が分解能の整数倍か |
| 振幅分解能 | ピーク振幅指定のとき、分解能の整数倍か |
| 最大駆動振幅 | 波形のピークが上限を超えていないか |
| 最大離調 | 離調が上限を超えていないか |

「AWG周期の整数倍」は実装上の細かい制約に見えますが、**任意の長さの波形を出せる装置は存在しない**という事実をそのまま反映したものです。

### 準静的ノイズ(トランズモン1台)

1回のショット中は一定で、ショット間でGaussian分布する周波数離調を、密度行列のアンサンブル平均として計算します。既定は無効です。

有効にすると、離調の標準偏差 $\sigma$ [rad/μs] とGauss-Hermite求積次数(3 / 5 / 7 / 9)を指定できます。次数を上げるほど平均が正確になり、計算量も増えます。

### ネットワーク専用の設定(トランズモン2台以上)

トランズモン数を2以上にすると、Circuit Studioの全レーンが実行対象になります。Pulse Labではq0・q1の基準離調と、全隣接ペアへ共通に使う交換結合 $J$ を指定します。q2以降の基準離調は現在0です。各トランズモンの周波数と非調和性はCircuit Studioの回路状態から送られます。

**相関準静的離調ノイズ**も指定できます。

- **共通 $\sigma$** [rad/μs] 全トランズモンに同じ標準偏差を与えます。$\sigma = 0$ ならアンサンブル平均を行いません
- **隣接相関係数 $r$**(−1〜1) 隣り合うトランズモンの離調ゆらぎがどれだけ連動しているか。$r = 1$ なら同じ方向に、$r = -1$ なら逆方向に揺れます。隣接しないペアは独立です
- **求積次数**(3 / 5) 軸ごとの次数。$N$台なら 次数$^N$ 本の軌道を重み付き平均します

共分散は三重対角行列 $\Sigma_{ij} = \sigma_i \sigma_j \cdot (1 \text{ if } i = j;\ r \text{ if } |i-j| = 1;\ 0 \text{ otherwise})$ です。

密度行列の次元増大を見積もり、作業量または応答要素数が上限を超える場合は実行前に止まります。スナップショット数は応答上限内へ自動的に縮小されることがあります。

## 実行

「実行上限管理」のセクションに、**推定計算量と上限**が表示されます。

```text
UIによる保守的な見積り: 約 12,345 / 25,000 ステップ
```

上限を超えると実行ボタンが無効になります。上限は構成ごとに違い、準位数や台数が増えるほど厳しくなります。**上限に当たったら、観測時間、Pulse本数、トランズモン数、準位数、スナップショット数のいずれかを減らしてください。**

実行できないときは、次のどれかが表示されます。

| 表示 | 原因 |
|---|---|
| 実行前に、強調表示されている項目を修正してください | 入力値が不正(負の幅、非有限値など) |
| ブロック名: 〜である必要があります | ハードウェア制約の違反。ブロックごとに列挙されます |

実行できない理由と制約の違反は、ツールバーの下と、メッセージの「実行」タブに出ます。実行に失敗した場合は「Pulseの実行に失敗しました」または「待ち時間の上限に達したため、実行を打ち切りました」と表示され、いずれも**前回の有効な結果を表示したまま**になります。

## 駆動波形

メッセージの「波形」タブに、実行の有無にかかわらず、いま設定されている波形が常に描かれます。

- $\Omega_x$ と $\Omega_y$ の2直交成分を [rad/μs] で表示
- 「Pulse終了」の縦線が、駆動が切れる時刻
- 観測時間がPulse幅より長いとき、**Pulse境界以降は制御がゼロになり、状態はアイドル観測を通じて発展を続けます**

位相を変えると $\Omega_x$ と $\Omega_y$ の配分が変わります。位相0ならX軸周り、π/2ならY軸周りの回転です。DRAG $\beta$ を入れると、$\Omega_x$ の微分に比例した成分が $\Omega_y$ 側に現れます。

## 結果の読み方

実行が終わると、メッセージの「結果」タブに状態エクスプローラーへの導線が出ます。時間発展した状態(占有数・密度行列・指標)は、作業領域を[Pulse 状態エクスプローラー](./pulse-state-explorer.md)に切り替えて読みます。以下はそこに出る主な項目です。

### サマリー

| 指標 | 意味 |
|---|---|
| Pulse終了時の純度 | 駆動が切れた瞬間の $\mathrm{Tr}(\rho^2)$ |
| 最終純度 | 観測時間の終わりでの純度 |
| 目標状態との重なり / 最終忠実度 | qutritでは目標状態との重なり(**リーケージ非正規化**)、2準位では閉じた系との忠実度 |
| 最大リーケージ $P_2$ | 軌跡全体での $\lvert 2\rangle$ 占有の最大値 |
| 最終リーケージ $P_2$ | 終了時点の $\lvert 2\rangle$ 占有 |

「Pulse終了時」と「最終」の2つがあるのは、Gate-awareの完了時忠実度と最終忠実度の関係と同じです。**その差が、駆動を切ったあと放置したことによる劣化**です。

シーケンス実行では「目標状態との重なり」は N/A になります。複数Pulseの合成先を単一の目標状態として定義していないためです。

### 占有確率と品質指標

各準位の占有確率・純度・忠実度を時間の関数として重ねたグラフです。**リーケージが起きる瞬間がそのまま見えます**。$P_2$ が駆動中に持ち上がってから戻るなら一時的な漏れ、戻らないなら実害のある漏れです。

### 最終密度行列

終了時点の密度行列を表示します(途中時刻の密度行列は[Pulse 状態エクスプローラー](./pulse-state-explorer.md)で読めます)。1台なら準位数そのもの(2×2 または 3×3)、2台以上なら $L^N\times L^N$(最大81×81)です。対角が占有確率、非対角がコヒーレンスです。

大きい行列では「行列要素を検索」を使います。行・列へ基底ラベル(例: `010`)または `#要素番号`(例: `#7`)を入力し、周辺幅±1〜±3を選んでください。選択したセルの複素値・絶対値と、その行列位置の周辺だけが表示されます。10次元以上では周辺表示が既定で、27次元以下なら「行列全体を表示」へ切り替えられます。

### 警告と制限事項

APIが返した適用範囲の注意が一覧されます。**RWAが破れる条件や、打ち切り準位数が足りない条件はここに出ます。** 警告が複数あるときは自動で開きます。

モデル詳細・レート・数値計算の診断・APIリクエストの中身は、詳細モードでのみ開けるドロワーとして用意されています。

## シーケンス実行のしくみ

qutritモデルでPulse回路にブロックがあるとき、Pulseラボは各ブロックを**順番に別々のAPIリクエストとして実行し、密度行列を次のブロックへ引き渡します**。

```text
ブロック1 実行 → 終了時の密度行列 ─┐
                                    ├→ ブロック2 の初期状態として使用 → …
共通環境（温度・T1・Tφ など）───────┘
```

観測時間の配分は自動です。各Pulse幅にパルス間待機を足したものが各ブロックに割り当てられ、余った時間は最後のブロックの後ろにアイドルとして付きます。スナップショット数もブロック数で分割されます。

Virtual Z(VZ)は**APIを呼びません**。時間を進めず、密度行列に $U = \mathrm{diag}(1, e^{-i\lambda}, e^{-i2\lambda})$ を適用して位相フレームを更新するだけです。これは実機の仮想Zゲートが時間を消費しないのと同じ扱いで、Gate-awareモデルでZ・S・Tの所要時間が0であることと対応しています。

ネットワークモデルでは動作が異なります。各レーンを時刻0から並行に配置し、レーン内のdriveだけをPulse間隔付きで直列化して、全スケジュールを1回のAPI要求で送ります。VZはそのレーンの後続Pulseへ位相として加算されるため、やはり時間は進みません。異なるレーンの時間区間が重なれば、局所driveは同時に作用します。

## 次のステップ

Pulseを並べたり波形を変えたりするには、作業領域で[Pulse 回路スタジオ](./pulse-circuit-studio.md)を開きます。

**軌跡を時刻ごとに読み解くには**、タイトル行で作業領域を[Pulse 状態エクスプローラー](./pulse-state-explorer.md)に切り替えてください。時刻カーソルを1本共有した指標タイムライン・確率比較・占有確率分布・カーソル時刻の密度行列が並びます。
