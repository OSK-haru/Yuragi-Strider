# ヘルプ / Q&A(`/help`)

アプリ内に組み込まれたQ&A画面です。**結果を見ていて手が止まったときに開く場所**として用意されています。指標の意味、値が食い違う理由、忠実度が落ちたときに何を試すかが、質問と答えの形で並んでいます。

このドキュメント側の解説([出力の定義](../../physics-model/outputs.md)など)が「何をどう計算しているか」を書くのに対し、アプリ内のQ&Aは「表示されている数字をどう読むか」に寄せてあります。

## 収録されている質問

| 質問 | 何が分かるか |
|---|---|
| 状態忠実度とは何ですか？ | ノイズを含む結果が理想の結果にどれだけ近いか。1に近いほど目標状態に近い |
| 純度とは何ですか？ | 状態がどれだけ純粋か／混合しているか |
| 有効操作時間とは何ですか？ | 忠実度がしきい値を下回る最初の時刻。「回路はどのくらいの時間使えるのか」への答え |
| 忠実度が低いのに純度が高いのはなぜですか？ | 2つが測っているものの違い |
| ノイズが大きいと忠実度が下がるのはなぜですか？ | ノイズが理想の軌跡から状態を引き離す仕組み |
| 完了時の忠実度と最終忠実度の違いは何ですか？ | 操作完了時点と、シミュレーション終了時点の違い |
| Yuragi-Striderはどのモデルを使用していますか？ | 現在の制御モデルと、将来対応予定のモデル |
| ハードウェアを正確に再現するシミュレーターですか？ | いいえ。簡略化された学習用モデルです |
| 忠実度が下がったときは何を試せばよいですか？ | 条件を変えて比較する手順 |

質問文はアプリ内の表示と同じです。答えの全文は画面で読んでください。ここに再掲すると、アプリ側を直したときにこちらが古くなるためです。

## とくに詰まりやすい2点

### 忠実度と純度は別のものを測っています

忠実度は**理想の目標にどれだけ近いか**、純度は**状態がどれだけ混合しているか**を見ます。そのため、状態が比較的純粋なまま、理想とは違う方向を向いていることがあり得ます。このとき忠実度は低く、純度は高いままになります。

[状態エクスプローラー](./state-explorer.md)のBloch球で言うと、純度の低下は球の**内側へ縮む**動き、忠実度の低下は理想状態の点から**離れる**動きです。方向がずれただけなら、縮まずに離れます。

### 完了時忠実度と最終忠実度がずれるのは正常です

完了時忠実度は意図した操作が終わった時点、最終忠実度はシミュレーション全体のタイムラインが終わった時点の値です。[計算パラメーター](./simulate.md)の総シミュレーション時間を回路の所要時間より長く取っている場合、その差の区間でも状態は環境と相互作用し続けます。**両者の差は「放置したことによる劣化」そのもの**です。

## 忠実度が落ちたときの手順

アプリ内Q&Aが勧めている進め方です。

1. まず**低ノイズ条件と高ノイズ条件で1回ずつ実行**し、有効時間がどう変わるかを比べる
2. 忠実度が急速に落ちる場合は、先にノイズレベルを下げる
3. そのうえで温度・磁束ノイズを個別に変えて比較する

目的は、**どの条件が状態を理想から最も強く引き離しているかを特定すること**です。複数のパラメーターを同時に動かすと、この切り分けができません。

## モデルの位置づけについて

この画面で説明される内容は、すべてアプリが使っている簡略化モデルに基づいています。現在のシミュレーションは学習用で、ゲートを考慮したLindbladベースのモデルです。厳密に校正されたハードウェアモデルではないため、**結果は選んだ前提条件のもとでの傾向であって、特定のデバイスに対する予測ではありません**。

この線引きの詳細は[前提と適用範囲](../../physics-model/assumuptions.md)と[現在の制限事項](../../limitations/current-limitations.md)を参照してください。
