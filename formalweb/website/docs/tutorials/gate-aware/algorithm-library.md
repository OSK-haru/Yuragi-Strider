# アルゴリズムのプリセット

回路をゼロから組む代わりに、代表的な量子アルゴリズムを読み込める一覧です。IDE画面の左のナビゲーター「アルゴリズム」に並んでいます。**Yuragi-Striderを初めて触るときの入口**として用意されています。

名前を押すと、その回路が[回路エディター](./circuit-studio.md)に読み込まれます。あとはツールバーの「シミュレーションを実行」を押すだけです。

:::warning[現在の回路は置き換わります]
プリセットの読み込みは、編集中の回路を上書きします。残しておきたい回路がある場合は、先に回路エディターの「エクスポート」で書き出してください。
:::

## 収録されているアルゴリズム

### Grover探索(2量子ビット)

- **分類** 探索アルゴリズム / 入門〜中級
- **要点** 振幅増幅・オラクル・拡散変換

4通りの状態から、CZゲートのオラクルで $\lvert 11\rangle$ だけに位相を反転させ、1回の拡散変換(振幅増幅)で測定確率を高めます。2量子ビットなら1回の反復で最適になるため、Groverの仕組みを最短で確認できます。

**見どころ** ノイズを強くしていくと、増幅されたはずの $\lvert 11\rangle$ の確率が他の状態へ漏れていきます。[状態エクスプローラー](./state-explorer.md)の「確率比較」で理想値との差が読めます。

### Grover探索(4量子ビット)

- **分類** 探索アルゴリズム / 中級(4量子ビット)
- **要点** 16状態・3回反復・多重制御X・拡散変換

16通りの状態から $\lvert 0100\rangle$ を探索します。位相オラクルのあとに、$H^{\otimes 4}$・$X^{\otimes 4}$・多重制御X・$X^{\otimes 4}$・$H^{\otimes 4}$ で構成した拡散変換を3回実行し、解の振幅を増幅します。

**見どころ** 2量子ビット版と違い、反復回数に最適値があります。拡散変換の列を削って反復を減らすと、振幅が増幅しきらないことを確認できます。

### 量子テレポーテーション

- **分類** 量子通信プロトコル / 入門
- **要点** エンタングルメント・ベル測定・古典条件付きゲート

エンタングルメントと2ビットの古典通信を使い、量子状態を q0 から q2 へ転送します。ベル対の生成・ベル測定・条件付き補正という量子通信の基本パターンをそのまま追えます。

**見どころ** この回路には MESSAGE と RECEIVED が含まれるため、状態エクスプローラーに「Message → Receive」パネルが追加され、状態がどこからどこへ移ったのかを直接見られます。

### マジック状態 $\lvert T\rangle$ の生成と劣化

- **分類** 量子誤り訂正 / 入門〜中級(2量子ビット)
- **要点** Tゲート・Clifford+T・Bloch球・デコヒーレンス

q0 に H・T を適用して、マジック状態 $\lvert T\rangle = (\lvert 0\rangle + e^{i\pi/4}\lvert 1\rangle)/\sqrt{2}$ を作ります。参照用の q1 には H だけを掛け、Clifford状態 $\lvert +\rangle$ を置いてあります。

H・S・CNOT だけで作れる状態(Clifford状態)は、Bloch球に内接する八面体の頂点にしか到達できません。$\lvert T\rangle$ はその頂点から45°ずれた、**八面体の外**を向いた状態です。誤り訂正符号の上では Clifford ゲートは符号を保ったまま直接実行できるのに、T だけは直接実行できません(Eastin-Knillの定理)。代わりにこのマジック状態を1個消費して T ゲートを1回実現します。実機で T ゲートが高コストとされる理由がここにあります。

**見どころ** [状態エクスプローラー](./state-explorer.md)のBloch球で q0 と q1 を見比べてください。q1 は $x$ 軸上の頂点ちょうどに乗り、q0 だけが赤道上を45°ずれた向きを指します。この「ずれ」がマジック状態の magic です。

シミュレーション時間を延ばすと、両方のBlochベクトルが原点に向かって縮みます。劣化したマジック状態は蒸留(magic state distillation)に投入できないため、これはそのまま「マジック状態には鮮度がある」という話になります。

:::note[両者の縮む速さは同じです]
T ゲートは $z$ 軸回りの回転で、緩和・位相緩和は $z$ 軸対称です。そのため $\lvert +\rangle$ と $\lvert T\rangle$ のBlochベクトル長は同じ速さで減衰します。ここで見るべき違いは減衰の速さではなく、**向き**です。
:::

### 3量子ビット反復符号

- **分類** 量子誤り訂正 / 中級(5量子ビット)
- **要点** 誤り訂正符号・シンドローム測定・条件付き補正

1つの論理量子ビットを3つの物理量子ビットに符号化します。q1 に X(ビット反転)故障を注入し、2つの補助量子ビットでシンドロームを測定して、条件付きゲートで自動的に誤りを訂正します。

**見どころ** 訂正が効いている状態と、ノイズを強めて訂正が追いつかなくなる状態を比較すると、誤り訂正の「効く範囲」が見えます。5量子ビットあるため、時間ステップ数は控えめから始めてください。

## 読み込んだあとにできること

プリセットは出発点であって、固定された教材ではありません。読み込んだ回路は普通の回路と同じように扱えます。

- [回路エディター](./circuit-studio.md)でゲートを足す・消す・角度を変える
- 右の[計算パラメーター](./simulate.md)で温度・磁束ノイズ・$T_1$ などを変えて再実行する
- 同じ回路をノイズ条件だけ変えて2回実行し、忠実度の落ち方を比べる
