# Gate-aware IDEワークスペース(`/ide`)

Gate-awareモードは、量子ゲートで回路を組み、**ゲートが有限時間かかる間に環境ノイズが作用する**という前提で状態の劣化を観察するためのワークスペースです。モデルの中身は[Gate-awareモデル](../../physics-model/control_models/gate-awaremodel.md)を参照してください。

回路の編集・条件の設定・実行・結果の観察は、すべて**1つのIDE画面**の中で行います。

## 画面の構成

```text
┌ タイトル行   [回路] [状態エクスプローラー]        表示 ▸ ナビゲーター / プロパティ / メッセージ ┐
├ ツールバー   [シミュレーションを実行]                                     データソース ┤
├──────────────┬───────────────────────────────┬───────────────────────┤
│ ナビゲーター │ 作業領域                      │ プロパティ            │
│  回路の概要  │  回路エディター               │  計算パラメーター     │
│  アルゴリズム│   または 状態エクスプローラー │  スナップショット     │
│              │                               │  ツール箱             │
├──────────────┴───────────────────────────────┴───────────────────────┤
│ メッセージ   [実行] [警告と問題] [診断]                                          │
└ ステータスバー  準備完了 · 接続 · 最終忠実度 · 前回の実行時間 ─────────────────────┘
```

| 場所 | 中身 | 説明 |
|---|---|---|
| 作業領域(回路) | 回路エディター | [回路エディター](./circuit-studio.md) |
| 作業領域(状態エクスプローラー) | 実行結果の観察 | [状態エクスプローラー](./state-explorer.md) |
| ツールバー・プロパティ・メッセージ | 実行、計算パラメーター、計算方法、警告、診断 | [実行と計算パラメーター](./simulate.md) |
| ナビゲーター | 回路の概要、アルゴリズムのプリセット | [アルゴリズムのプリセット](./algorithm-library.md) |

作業領域の表示は、タイトル行の「回路」「状態エクスプローラー」で切り替えます。

## ペインの開閉と大きさ

一般的なIDEと同じように、ペインの配置を自分に合わせて変えられます。

| 操作 | 方法 |
|---|---|
| ペインを閉じる | ペインの見出し右端の × |
| 閉じたペインを開く | タイトル行の「表示」で、ナビゲーター / プロパティ / メッセージを押す |
| 大きさを変える | ペインの境界線をドラッグする。境界線にフォーカスを当てて矢印キーでも動かせます(Home / End で最小 / 最大) |
| 境界線を初期値に戻す | 境界線をダブルクリック |
| 配置をすべて初期状態に戻す | 「表示」の「配置を戻す」 |

配置はブラウザに保存され、次に開いたときも引き継がれます。画面幅が狭い(760px以下)ときは、境界線を使わずペインを縦に積みます。

:::note[ガイドツアー中のペイン]
[ガイドツアー](../index.md#ガイドツアー)が閉じているペインを指すときは、そのあいだだけペインが表示されます。保存した配置は変わりません。
:::

## 標準的な流れ

```text
回路を用意する ─ 左の「アルゴリズム」から読み込む、または回路エディターで組む
       │
       ↓
条件を決めて実行 ─ 右の計算パラメーター、ツールバーの「シミュレーションを実行」
       │
       ↓
結果を読む ─ 作業領域を「状態エクスプローラー」に切り替える
```

はじめて触る場合は、左の「アルゴリズム」からGrover探索を読み込み、そのまま「シミュレーションを実行」を押すのが最短です。

## 回路と結果の関係

回路エディター・実行・状態エクスプローラーは**同じ1つの回路**を共有しています。回路エディターで置いたゲートが、そのまま実行対象になります。

一方、**シミュレーション結果は実行した瞬間の回路に紐づきます**。実行後に回路を編集すると、状態エクスプローラーは「表示中の回路に対応する結果がありません」と表示し、古い結果を出しません。回路と結果がずれた図を見せないための仕様です。

## 以前の画面のURL

通常モードは以前、シミュレーションワークスペース・回路スタジオ・アルゴリズム一覧・状態エクスプローラーの4画面に分かれていました。現在はこのIDE画面に一本化しています。以前のURLを開くと、IDE画面へ移ります。

| 以前のURL | 移動先 |
|---|---|
| `/simulate`、`/circuit-studio`、`/algorithm-library` | `/ide`(回路) |
| `/state-explorer` | `/ide`(状態エクスプローラー) |

## 用語の対応

画面上の表記と、ドキュメント側の用語は次のように対応します。

| 画面の表記 | ドキュメントでの呼称 |
|---|---|
| 忠実度 | 状態忠実度 $F$ |
| 純度 | $\mathrm{Tr}(\rho^2)$ |
| 有効操作時間 | 忠実度がしきい値を初めて下回る時刻 |
| ゲートの実行方法 | ゲートコンパイルモード |
| 時間発展の解法 | [RK4](../../physics-model/propagation/RK4.md) / [明示的CPTP](../../physics-model/propagation/CPTP.md) |
