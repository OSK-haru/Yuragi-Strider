# 状態エクスプローラー

IDE画面の作業領域で「状態エクスプローラー」を選んでいるときの表示です。実行済みのGate-awareシミュレーションについて、**状態が時間とともにどう崩れていったか**を読みます。ここでは計算は走りません。すでに保存されたスナップショットを見る場所です。

:::note[Gate-aware専用]
表示されるのはGate-awareシミュレーションの回路スナップショットだけです。Pulseラボの結果はここには読み込まれません。Pulseの軌跡には専用の[Pulse 状態エクスプローラー](../pulse-level/pulse-state-explorer.md)があります。
:::

## 結果が表示されないとき

この画面には2種類の「結果なし」があります。

| 表示 | 状況 | 対処 |
|---|---|---|
| 結果なし | まだ一度も実行していない | 「回路エディターに戻る」で回路を用意し、ツールバーの「シミュレーションを実行」を押す |
| 再実行が必要 | 実行後に回路を編集した | 現在の回路をもう一度実行する |

後者は、**回路と結果がずれた図を見せないための仕様**です。保存済み結果が現在の回路と一致するかを毎回照合し、一致しない場合は古い結果を出しません(何量子ビットの結果を保持しているかも表示されます)。

## 表示項目の選び方

画面上部の「表示項目」メニューで、パネルの表示・非表示を切り替えます。「すべて表示」「すべて非表示」もここにあります。各パネルの見出しの × で個別に隠せます。

**初期状態では既存の8項目(再生バー・物理時間・指標タイムライン・確率比較・出力確率・Bloch球・密度行列・環境レート)がすべて開いています。** この選択は、右の計算パラメーターの下にある「ツール箱」と同じものです。どちらで切り替えても、もう一方に反映されます。

### ツール箱で追加の指標を選ぶ

右の計算パラメーターの下にある「ツール箱」で、実行前に追加の指標を選べます。選んだものだけを計算し、このページの末尾にパネルとして並べます。表示中の値から計算できてしまう指標(線形エントロピー = 1 − 純度、忠実度から決まるビュレス距離、1量子ビットのエントロピーなど)は、最初から並べていません。

| 区分 | 指標 | 計算のしかた |
|---|---|---|
| 状態の指標 | フォン・ノイマン・エントロピー(2量子ビット以上の組)、コンカレンス、ネガティビティ、相互情報量、理想状態とのトレース距離、2量子ビット以上に作用するパウリ演算子の期待値 | 各スナップショットの密度行列から計算します。追加の実行はなく、再生バーの時刻と連動します |
| プロセスの評価 | 平均ゲート忠実度、χ 行列 | 入力状態を変えて回路を繰り返し実行します。3量子ビットまでは厳密なトモグラフィー(4ⁿ 回)、4〜6量子ビットはモンテカルロ推定(標準誤差と95%区間つき)です。χ 行列は3量子ビットまでです。測定や古典条件付きゲートを含む回路では定義できません |
| 環境の検証 | T1 スイープ、Ramsey(T2*)スイープ | 現在の環境設定で行う1量子ビットの別実験です |

プロセスの評価とスイープは、通常の実行が終わったあとに順に計算します。計算中のパネルには「計算中…」と出ます。読み込んだ結果ファイルには、これらの追加実行の結果は含まれません。

利用できるパネルは結果の内容によって変わります。Bloch球と密度行列はスナップショットがあるとき、「Message → Receive」は回路に MESSAGE と RECEIVED の両方が置かれているときにだけ現れます。

## 各パネル

### Message → Receive

量子テレポーテーションのように、状態がある量子ビットから別の量子ビットへ移る回路のためのパネルです。転送元と転送先の状態を並べ、**状態が本当に移ったのか、途中でどれだけ劣化したのか**を見ます。ノイズありとノイズなし(理想)を同時に表示します。

### 再生バー

時刻カーソルを動かすための操作系だけを、パネルの外に独立して出したものです。「物理時間」パネルを閉じていても時刻を動かせるように分けてあります。図は描かず、再生・スライダー・◀ ▶ だけが並びます。

「物理時間」パネルを開いているなら、そちらにも同じ操作系が付いているので、この再生バーは不要です。既定では非表示になっています。

### 物理時間

回路を実時間の軸に並べ、再生しながら状態の変化を追うパネルです。どのゲートがどの時刻に実行されているか、測定がいつ入るかが見えます。**再生位置を動かすと、他のパネルの表示時刻も一緒に動きます。**

### 指標タイムライン

忠実度・純度・区間状態変化を時間の関数として描きます。忠実度そのものが理想状態との近さを表す量なので、**理想側の系列は重ねません**。線を減らして、読む軸を1本に保つためです。理想状態との比較は「確率比較」「Bloch球」「密度行列」で行います。

「有効操作時間」は、このグラフが[計算パラメーター](./simulate.md)で設定した忠実度しきい値を初めて下回る時刻です。

### 確率比較

各計算基底状態の確率を、**ノイズあり・理想・最終結果**で比較します。「本来 $\lvert 11\rangle$ に集まるはずの確率が、どこへ漏れたか」を読むのに最も向いたパネルです。

### 出力確率

最終状態を計算基底で展開した確率分布です。スナップショットを切り替えると、途中時刻の分布も見られます。

### Bloch球

各量子ビットの縮約状態をBloch球上に描きます。Gate-awareの状態は2準位に閉じているので、この縮約で情報が失われません(Pulse-level側にBloch球が無いのはこの前提が成り立たないためです)。理想状態のスナップショットがある場合は「Gate-aware 状態」と「理想状態(ノイズなし)」が左右に並び、**同じ時刻で見比べられます**。

ノイズを受けた状態はBloch球の**内側**へ縮んでいきます。表面から離れる距離が、そのまま純度の低下です。

### 密度行列

Bloch球と同じスナップショットについて、多量子ビットの完全な状態 $\rho$ を表示します。Bloch球は1量子ビットごとの縮約なので、**エンタングルメントは密度行列でしか読めません**。理想状態の密度行列も並べて表示されます。

表示モードによって、セルの色の意味が変わります。

| モード | 色 | 濃さ |
|---|---|---|
| 絶対値 | 文字色 | 絶対値 |
| 実部・虚部 | 正は赤、負は青 | 値の大きさ |
| 位相 | 0=文字色、$+\pi/2$=橙、$\pm\pi$=赤、$-\pi/2$=青 | 絶対値 |

位相は一周すると元の色に戻るので、$+3.1$ と $-3.1$ のようにほぼ同じ位相は同じ色になります。色分けの根拠は[画面表示の設計方針](../../overview/ui-design.md)にまとめています。

### 環境レート

この実行で実際に使われた緩和時間と緩和レートを並べたパネルです。$T_1$ は占有数の緩和、$T_2$ は位相の緩和にかかる時間の目安で、**回路の所要時間がこれらに近づくほど忠実度が落ちます**。

[計算パラメーター](./simulate.md)で入力するのは温度・磁束ノイズ・デバイス品質といった物理条件で、そこから[散逸モデル](../../physics-model/dissipation-model.md)を通って求まった値がここに出ます。**入力した条件が最終的にどんな時間スケールになったのか**を確かめる場所です。下段には換算前の緩和レート(生値)も並びます。

出る値は「基準 $T_1$ / 実効 $T_1$ / 基準 $T_\varphi$ / 実効 $T_2$」の4つで、**基準**が入力条件そのものから決まる値、**実効**がデバイス品質などを織り込んだあとの値です。

環境条件を変えて結果がどう動いたかを追うときは、まずこのパネルで実効 $T_1$・$T_2$ が意図どおり動いたかを確認してください。

## 前回の実行と見比べる

「表示項目」メニューの下の帯で、**いまの結果を保持して、次の実行と重ねて読む**ことができます。

| 操作 | 意味 |
|---|---|
| この実行を保持 | いまの結果を1件だけ取っておく |
| 比較表示 | 保持した実行を図に重ねるかどうか。既定は切 |
| いまの実行に差し替え | 保持を現在の結果で置き換える |
| 保持を解除 | 保持を捨てる |

保持できるのは**1件・画面全体で1つ**です。パネルは全部で1つのスナップショット位置を共有しているため、パネルごとに別の実行を保持できると、隣り合う図が別々の条件を指してしまいます。

### 重ねられるのは「環境だけを変えた実行」です

2本の差を**環境の寄与**として読めるのは、回路と観測条件が同じまま環境パラメタだけを変えた場合に限ります。パルスや観測窓まで動かすと、差がどこから来たのか分けられません。

そのため、保持した時点の

- 回路の構造(`circuitConfigSignature`)
- 観測窓(`duration_us`・`time_steps`)
- 入力の与え方(`input_mode`)

を指紋として覚えておき、**現在の実行と一致しなくなった時点で保持を自動的に破棄します**。温度・デバイス品質・磁束ノイズ・$T_1$・$T_\phi$ といった環境側は指紋に含めないので、これらを変えて再実行しても保持は残ります。

読めない比較を残しておくより、履歴ごと消して保持し直してもらうほうが正しい、という判断です。

### 重ねる線は常に1本だけです

比較線が出るのは「**指標タイムライン**」と「**確率比較**」の2枚だけです。指標タイムラインはすでに複数の系列が走っているため、保持側を全部足すと線が倍になって読めなくなります。そこで**どの指標を重ねるかを凡例のプルダウンで選ぶ**方式にしました(忠実度・純度・区間状態変化)。

保持した実行の線は、現在の実行の線より細い点線で描かれます。カーソル時刻での数値と差も併記されます。

## 結果を書き出す

同じ帯の右端に「**結果を書き出す**」があります。表示中の実行を、**それを生んだ入力ごと** JSON ファイルとして保存します。

ファイル名は `gate-aware結果_YYYYMMDD-HHMMSS.json` です。中身は次の構成です。

| キー | 内容 |
|---|---|
| `meta` | 書き出した時刻(ISO 8601)と生成元 |
| `inputs.circuit_config` | その結果を計算した回路 |
| `inputs.gate_duration_defaults` | 各ゲートの所要時間の既定値 |
| `result` | 応答そのもの(指標タイムライン、スナップショット、出力確率、診断、警告) |

入力を必ず同梱しているのは、**結果だけでは何の条件の話か後から読めない**ためです。受け取った側は `inputs` を見れば同じ条件を再現できます。

## 結果を読み込む

書き出したファイルは、同じ帯の「**結果を読み込む**」から読み戻せます。まだ一度も実行していない状態（「結果がありません」の画面）にも同じボタンがあるので、**人から受け取ったファイルをそのまま開けます**。

読み込むと、次の3つが**同時に**復元されます。

| 復元されるもの | どこへ入るか |
|---|---|
| 結果 | 状態エクスプローラーの各パネル |
| 回路 | [回路エディター](./circuit-studio.md)の編集中の回路 |
| ゲート所要時間の既定値 | [計算パラメーター](./simulate.md)の設定 |

### なぜ回路まで一緒に戻すのか

この画面は「**いま編集中の回路と、表示中の結果が対応している**」ことを前提に図を描いています。実行後に回路を編集すると結果を隠すのも、同じ理由です。

結果だけを読み込むと、この前提が壊れます。画面の回路と図の条件が食い違い、その図が何の条件のものか画面から辿れなくなるためです。そこで読み込みは、**結果とその入力をセットで復元します**。これにより、読み込んだあとも「画面の設定 = 図の条件」が成り立ったままになります。

:::warning[読み込むと現在の回路は置き換わります]
結果の読み込みは、編集中の回路を上書きします。残しておきたい回路がある場合は、先に[回路エディター](./circuit-studio.md)でエクスポートしてください。保持していた比較も破棄されます（読み込んだ結果は別条件のものなので、重ねて読める保証がないためです）。
:::

### 読み込んだ結果には印が付きます

読み込んだ結果を表示しているあいだ、パネルの上に**「読み込んだ結果を表示しています」**と出ます。

計算し直した結果と見分けが付かないと、**その数字がいまの設定で得られたものだと誤解される**ためです。この印が消えるのは、実際にシミュレーションを再実行したときだけです。

### 読み込めないファイル

次のものは、図を描く前に弾かれます。

| 弾かれるもの | 理由 |
|---|---|
| Pulseモードの結果ファイル | モードが違います。[Pulse 状態エクスプローラー](../pulse-level/pulse-state-explorer.md#結果を読み込む)から開いてください |
| Yuragi-Strider以外のJSON | 結果ファイルではありません |
| 将来のバージョンのファイル | 黙って誤読するより、読めないと言うほうが安全です |
| 回路を含まない結果 | エディターへ復元できず、「画面の設定 = 図の条件」を保てません |

なお、結果の中身（軌跡が物理的に妥当か等）までは検査しません。それはシミュレーターが計算して返したものであり、読み込み時に再計算して確かめる性質のものではないためです。

:::tip[線が1本にしか見えないとき]
環境パラメタの変化が小さいと、2本がほとんど重なって1本に見えます。差が線幅に埋もれている場合はその旨が図の上に表示されるので、$T_1$ を1桁下げるなど大きめに変えて再実行してください。
:::

## パネル間の時刻は連動します

物理時間の再生位置、Bloch球のスナップショット、密度行列のスナップショットは互いに同期しています。どれか1つを動かすと、最も近い時刻のスナップショットに他も揃います。**同じ瞬間を複数の見方で同時に見るための設計**です。

初期表示は「回路の後」のスナップショット(なければ最後の列の境界)が選ばれます。回路が終わった直後の状態が、まず知りたい状態だからです。

## 画面下部の要約

量子ビット数・密度行列の次元($2^n \times 2^n$)・保存されているスナップショット数が表示されます。スナップショットが0個の場合は、[計算パラメーター](./simulate.md)のサンプリング設定が無効になっている可能性があります。
