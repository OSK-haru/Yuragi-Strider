# 画面別チュートリアル

Yuragi-Striderの各画面が「何をする場所か」「どこを操作すると何が変わるか」を、画面ごとに説明します。物理モデルそのものの説明は[物理モデル詳細](../physics-model/overview.md)を参照してください。ここでは**操作**を扱います。

## 2つのワークスペース

アプリはまず2つのモードに分かれています。

| ワークスペース | 扱う対象 | チュートリアル |
|---|---|---|
| Gate-aware | 量子ゲートで組んだ回路。ゲートに有限の所要時間を与え、その間のノイズを見る | [Gate-aware 編](./gate-aware/index.md) |
| Pulse-level | ゲートより下の層。マイクロ波パルスの波形そのものからトランズモンの応答を追う | [Pulse-level 編](./pulse-level/index.md) |

2つのモードは状態を共有しません。Gate-awareで実行した結果はPulse側には現れず、その逆も同じです。

## ホーム画面(`/`)

起動直後に表示されるのがホーム画面です。ここには**行き先の選択**と**ガイドツアーの入口**の2つがあります。

画面上部の `ENGINE / KERNEL / MODEL / SOLVER` は、いま動いている計算構成の表示です(既定は Gate-aware開放系モデル + Lindblad / RK4)。

### 行き先を選ぶ(四角柱のドラム)

行き先は横並びではなく、**四角柱が回るように1面ずつ正面に出てくる**形で並んでいます。面は4つあり、5秒ごとに自動で送られます。カーソルを乗せているあいだ、またはキーボードフォーカスが当たっているあいだは止まります。

| 面 | ボタン | 行き先 |
|---|---|---|
| MODE 01 / GATE-AWARE — 通常モード | 通常モードを開始 | Gate-awareの[IDEワークスペース](./gate-aware/index.md)。まずはこちらから |
| MODE 02 / PULSE — PULSEモード | PULSEモードを開始 | [Pulse IDE](./pulse-level/index.md) |
| MODE 03 / ATTACK — 攻撃シミュレーター | 攻撃シミュレーターを開始 | 攻撃シミュレーター(コマンドターミナルから操作する実験的なモード) |
| REF 04 / DOCUMENTATION — 公式ドキュメント | ドキュメントを開く | このドキュメントサイト(新しいタブ) |

`←` `→` `↑` `↓` キーでも面を送れます。[設定メニュー](#設定メニュー)でアニメーションを切っている場合、および OS 側で「視差効果を減らす」を有効にしている場合は、自動送りが止まり、手動でのみ切り替わります。

### ガイドツアー(チュートリアル)

ドラムの下に、**ナビペットが画面を案内するガイドツアー**が2本あります。詳しくは[ガイドツアー](#ガイドツアー)を参照してください。

## 共通のナビゲーション

すべての画面の最上部に、細い計器レールが常に表示されます。

| 表示 | 意味 |
|---|---|
| `YURAGI-STRIDER` | 製品名 |
| `SIM / GATE-AWARE` などの符号 | 現在いる画面の識別子 |
| `DOCS ↗` | このドキュメントサイトを新しいタブで開きます |

右端の `MENU` ボタンでページ一覧が開きます(`Esc`、または画面の他の場所をクリックすると閉じます)。開いている間、ボタンの表示は `CLOSE` に変わります。

:::info[モードをまたぐ移動はホーム経由]
メニューに出るのは**いま自分がいるワークスペースの画面だけ**です。Gate-awareの画面からPulseの画面へ直接は飛べません。いったん「ホーム」に戻ってから、もう一方のモードを選び直してください。これはモードごとに状態が独立しているためです。
:::

## 設定メニュー

メニューの最下部に、4つのスイッチがあります。設定はブラウザに保存され、次回以降も引き継がれます。

| スイッチ | 既定 | 効果 |
|---|---|---|
| ダークモード | OSの設定に追従 | 画面の明るさと配色を切り替えます。一度切り替えると、その選択が保存されます |
| アニメーション | 入 | 演出・遷移エフェクトの表示。切ると、ホームのドラムの自動送りと、状態エクスプローラーの自動再生が止まります |
| ガイドペット | 入 | 画面右下に常駐するナビペットの表示。切るとガイドツアーの案内役も出なくなります |
| 詳細モード | 切 | 内部情報(API・実行基盤・生データ・内部識別子)を表示します |

### 詳細モードで増える表示

**詳細モードは既定では切**です。ONにすると、通常は隠れている次の項目が現れます。

| 画面 | 増える表示 |
|---|---|
| [IDEワークスペース](./gate-aware/simulate.md) | 計算エンジンの内部名(`Python dense (standard)` など)、「API デバッグ / リクエストのスナップショット」ドロワー |
| [Pulse IDE](./pulse-level/pulse-lab.md) | ナビゲーターの[モデル識別情報](./pulse-level/pulse-lab.md#詳細モードで出る識別情報)、実行基盤(バックエンド)の選択欄、モデル詳細・レート・数値計算の診断・APIリクエストの各ドロワー |

このドキュメントで「詳細モードでのみ」と書かれている表示は、すべてこのスイッチのことです。**通常の操作に詳細モードは必要ありません。** 実際のコードと見合わせて計算の中身を確認したいときだけ使ってください。

## ガイドツアー

ホーム画面には、**ナビペットが画面上の見るべき場所を光らせながら案内するガイドツアー**が2本あります。量子回路の予備知識は不要です。

| コース | 所要 | 内容 |
|---|---|---|
| はじめての量子回路 | 約4分 | 量子ビットとゲートの話から、ベル回路を自分で組んで動かし、結果の読み方まで |
| ゆらぎ実験 | 約3分 | 回路はそのままで条件だけを変え、答えがどれだけ濁るかを3回の実行で比べます。1本目のあとにどうぞ |

「はじめる」を押すと開始します。ツアーはホームから[IDEワークスペース](./gate-aware/index.md)へ移り、回路エディター → 実行 → 状態エクスプローラーの順に進みます。作業領域の切り替えや、閉じているペインの表示もツアーが行うので、自分で操作する必要はありません。

進行中は、画面右下のナビペットに次の操作が出ます。

| ボタン | 動作 |
|---|---|
| つぎへ / おわり | 次の場面へ進みます |
| もどる | ひとつ前の場面へ戻ります |
| とばす | 操作待ちの場面を、実際に操作せずに飛ばします |
| 終了 | ツアーを中断します(画面上部の進捗バーの右端) |

**操作待ちの場面では、実際に手を動かすまで先へ進みません。** 条件を満たすと、ボタンを押さなくてもツアーが自分から次へ進みます。判定は操作の履歴ではなく**いまの回路の形**を見ているので、置き直したり元に戻したりしても正しく判定されますし、途中で寄り道しても構いません。

修了したコースはホーム画面に「修了済み」と表示され、「もう一度受ける」で何度でもやり直せます。この記録もブラウザに保存されます。

:::note[ガイドペットを切っているとき]
[設定メニュー](#設定メニュー)で「ガイドペット」を切っていると案内役が出ません。ツアーを使うときは入れておいてください。
:::
