# 理論を学ぶ

このセクションは、Yuragi-Striderが内部で行っている計算を**物理と数学の側から理解する**ための教科書です。

シミュレーターは「環境パラメータを入れると密度行列が出てくる箱」ではありません。入力から出力までの各段階には、それぞれ対応する物理の理論があります。ここではその理論を、定義から導出まで順に追える形で説明します。

## 「物理モデル詳細」との違い

| | このセクション(理論を学ぶ) | [物理モデル詳細](../physics-model/overview.md) |
|---|---|---|
| 答える問い | **なぜ**そうなるのか | **何を**実装しているか |
| 書き方 | 定義 → 導出 → 例 → 演習 | 仕様・数値・識別子・検証結果 |
| 読む目的 | 理論を身につける | 実装の挙動を正確に知る |

同じ式が両方に登場することがありますが、こちらでは「その式がどこから来たか」を扱い、あちらでは「その式をどのパラメータでどう使っているか」を扱います。各ページの末尾から対応する仕様ページへ移動できます。

## 前提知識

次のものを知っていれば読み進められます。知らない項目があっても、初出の場所で最低限の説明を入れてあります。

- **線形代数**: 複素ベクトル、行列の積、エルミート共役、固有値・固有ベクトル、トレース
- **微分方程式**: 1階線形常微分方程式、指数関数の解
- **複素数**: オイラーの公式 $e^{i\theta} = \cos\theta + i\sin\theta$

量子力学を学んだ経験は前提としません。第1章は量子状態の表し方から始めます。

## 処理レイヤーと理論の対応

Yuragi-Striderの計算は次の順に進みます。左の列が実際の処理、右の列がそれを支える理論です。

| 処理レイヤー | 何をしているか | 対応する章 |
|---|---|---|
| — | 状態を数として書く | [1. 量子状態と密度行列](./quantum-state.md) |
| — | 時間発展の基本形 | [2. ハミルトニアンとユニタリ発展](./unitary-dynamics.md) |
| 入力 | 環境を方程式に組み込む | [3. 開放量子系とGKSL方程式](./open-systems.md) |
| 入力 | 環境パラメータ → 物理レート | [4. デコヒーレンスと有限温度](./decoherence.md) |
| 制御(Gate-aware) | ゲート → ハミルトニアン | [5. ゲートと有効ハミルトニアン](./effective-hamiltonian.md) |
| 制御(Pulse-level) | パルス → ハミルトニアン | [6. 駆動、回転系、トランズモン](./pulse-control.md) |
| 時間発展 | 方程式を数値で解く | [7. 数値積分の理論](./numerical-integration.md) |
| 時間発展 | 発展を「写像」として見る | [8. 量子チャネルとCPTP](./quantum-channels.md) |
| 出力 | 結果を1つの数にまとめる | [9. 評価指標の数理](./metrics.md) |

さらに、Pulse-levelモデルには独立した課程を用意しています。

| 課程 | 内容 |
|---|---|
| [パルス編(全7章)](./pulse/index.md) | トランズモンの物理、パルス整形、漏れとDRAG、多準位散逸、準静的ノイズ、結合対、数値的作法 |

第6章がパルス制御の全体像、パルス編がその先の各論です。

## 読みかたの3コース

**最短コース(何が起きているか掴みたい)**
第1章 → 第3章 → 第4章 → 第9章

密度行列とは何か、環境は何をするのか、出てきた数字は何を意味するのか、の3点だけを押さえます。

**標準コース(モデル全体を理解したい)**
第1章 → 第2章 → 第3章 → 第4章 → 第5章 → 第7章 → 第9章

Gate-awareモデルの計算を最初から最後まで追えるようになります。

**精読コース(実装を検証・改造したい)**
全章を順に。特に第7章と第8章は、数値解法の選択がなぜ結果を変えうるのかを扱います。

パルス制御に興味がある場合は、どのコースでも第6章を加えてください。さらに深く学ぶなら、本編を終えたあとに[パルス編](./pulse/index.md)を履修してください(第1〜3章と第6章が前提です)。

## このセクションの限界

:::warning[教科書ではありますが、教科書の代わりではありません]
ここに書かれているのは、Yuragi-Striderを理解するのに必要な範囲の理論です。量子力学や開放量子系の体系的な教科書ではありません。

特に次の点は簡略化しています。

- GKSL方程式は**導出のスケッチのみ**を示し、厳密な微視的導出は行いません
- 測定理論は射影測定に限り、一般化測定(POVM)は扱いません
- 誤り訂正、複雑性理論、量子アルゴリズムの理論は扱いません

なお、誤り訂正の理論そのものは扱いませんが、IDEの左の[アルゴリズムのプリセット](../tutorials/gate-aware/algorithm-library.md)には3量子ビット反復符号とマジック状態を収録しています。動かして感触をつかむことはできます。

より深く学ぶための原典は[参考文献](../physics-model/references.md)にまとめてあります。
:::

また、Yuragi-Striderは**校正済みのハードウェアモデルではありません**。ここで学ぶ理論は正しいものですが、シミュレーターが出す数値が特定の実機を再現するわけではないことに注意してください。適用範囲は[前提と適用範囲](../physics-model/assumuptions.md)を参照してください。

## 演習について

各章の末尾に演習があります。紙の上で解けるものと、実際にYuragi-Striderを動かして確かめるものが混ざっています。後者には 🔬 を付けてあります。🔬 の手順では、画面に表示される日本語の項目名を使います。Gate-awareでは「回路スタジオで編集 → シミュレーションワークスペースで実行 → 状態エクスプローラーで観察」、Pulse-levelでは「Pulse 回路スタジオで波形を編集 → Pulseラボで環境を設定・実行」という順に進めてください。

理論が正しく実装されているかを自分の手で確かめられることが、このシミュレーターの目的の一つです。理論から予測を立て、シミュレーターで検証し、一致を確認する。この往復が最も学習効率の高い使い方です。
