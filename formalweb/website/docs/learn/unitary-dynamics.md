# 2. ハミルトニアンとユニタリ発展

:::info[このページで学ぶこと]
- Schrödinger方程式と、その解としての行列指数 $e^{-iHt}$
- 密度行列版の時間発展(von Neumann方程式)
- Pauli回転の閉じた形と、量子ゲートがすべて回転として書けること
- 時間依存ハミルトニアンをどう扱うか(区分定数近似の根拠)

**対応する処理レイヤー**: 時間発展の骨格(制御レイヤーと時間発展レイヤーの共通土台)
:::

## 2.1 Schrödinger方程式

閉じた量子系の状態は、次の微分方程式に従って時間発展します。

$$
i\hbar\,\frac{d}{dt}|\psi(t)\rangle = H(t)\,|\psi(t)\rangle
$$

$H$ は**ハミルトニアン**と呼ばれるエルミート行列で、系のエネルギーを表します。

:::note[単位系]
Yuragi-Striderは $\hbar = 1$ の単位系を採用します。この規約ではハミルトニアンの成分が**角周波数**の次元を持ち、単位は rad·μs⁻¹ です。時間は μs、レートは μs⁻¹ です。

$\hbar$ が消えるので、以下ではすべて $\hbar = 1$ で書きます。
:::

$H$ が時間に依存しない場合、この方程式は形式的にスカラーの $\dot{x} = -iax$ と同じで、解は指数関数です。

$$
|\psi(t)\rangle = U(t)\,|\psi(0)\rangle,
\qquad
U(t) = e^{-iHt}
$$

### 行列指数とは

行列の指数関数は、スカラーと同じ級数で定義されます。

$$
e^{M} = \sum_{k=0}^{\infty} \frac{M^k}{k!} = I + M + \frac{M^2}{2} + \cdots
$$

エルミート行列 $H$ は固有分解 $H = V\operatorname{diag}(\lambda_j)V^\dagger$ を持つので、実際の計算はこの形が便利です。

$$
e^{-iHt} = V\operatorname{diag}\!\left(e^{-i\lambda_j t}\right)V^\dagger
$$

**固有ベクトルは変化せず、固有値に応じた位相 $e^{-i\lambda_j t}$ が付くだけ**です。時間発展の本質はこれに尽きます。

:::warning[$e^{A}e^{B} \ne e^{A+B}$]
$A$ と $B$ が可換でない場合、この等式は成り立ちません。量子力学のほとんどの困難はここから来ます。第5章の有効ハミルトニアン構成も、第7章の数値積分も、第8章の区分定数近似も、すべてこの非可換性への対処です。
:::

### ユニタリ性と確率保存

$H$ がエルミート($H^\dagger = H$)であることから

$$
U^\dagger U = e^{iH^\dagger t}e^{-iHt} = e^{iHt}e^{-iHt} = I
$$

つまり $U$ は**ユニタリ**です。ユニタリ変換はベクトルの長さを変えないので、$\langle\psi|\psi\rangle = 1$ が常に保たれます。確率の総和が 1 であり続けるということです。

逆に、確率を保存する可逆な変換はユニタリでなければなりません。**量子ゲートがすべてユニタリ行列である理由**はここにあります。

## 2.2 密度行列の時間発展

$\rho = \sum_i p_i |\psi_i\rangle\langle\psi_i|$ の各項に $U$ を作用させると

$$
\rho(t) = U(t)\,\rho(0)\,U^\dagger(t)
$$

両辺を微分すると、微分形が得られます。

$$
\frac{d\rho}{dt}
= \frac{dU}{dt}\rho_0 U^\dagger + U\rho_0 \frac{dU^\dagger}{dt}
= -iH U\rho_0U^\dagger + U\rho_0U^\dagger (iH)
= -i\big[H, \rho\big]
$$

ここで $[A,B] = AB - BA$ は交換子です。この式を**von Neumann方程式**といいます。

$$
\boxed{\ \frac{d\rho}{dt} = -i\big[H(t), \rho\big]\ }
$$

:::tip[GKSL方程式の第1項の正体]
[Lindblad方程式](../physics-model/lindblad.md)の第1項 $-i[H(t),\rho]$ は、まさにこのvon Neumann方程式です。**環境がなければGKSL方程式はvon Neumann方程式に一致します。** 第3章で追加する第2項が、環境の効果をすべて担っています。
:::

ユニタリ発展は純度を変えません。

$$
\operatorname{Tr}\big[(U\rho U^\dagger)^2\big] = \operatorname{Tr}\big[U\rho^2U^\dagger\big] = \operatorname{Tr}(\rho^2)
$$

Bloch球でいえば、ユニタリ発展は**回転**であり、球の半径 $|\vec r|$ を変えません。純度が下がるのは環境が関わるときだけです。

## 2.3 Pauli回転 — ゲートの正体

1量子ビットのハミルトニアンは、Pauli行列の実線形結合で必ず書けます。$\hat{n}$ を単位ベクトルとして $H = \frac{\omega}{2}\,\hat{n}\cdot\vec{\sigma}$ とおくと、$(\hat n\cdot\vec\sigma)^2 = I$ という性質から級数が閉じます。

$$
e^{-i\frac{\theta}{2}\hat{n}\cdot\vec{\sigma}}
= \cos\frac{\theta}{2}\,I - i\sin\frac{\theta}{2}\,\big(\hat{n}\cdot\vec{\sigma}\big),
\qquad \theta = \omega t
$$

導出は次のとおりです。$A = \hat n\cdot\vec\sigma$ とおくと $A^2 = I$ なので $A^{2k} = I$、$A^{2k+1} = A$ です。級数を偶数次と奇数次に分けると

$$
e^{-i\frac{\theta}{2}A}
= \sum_k \frac{(-i\theta/2)^{2k}}{(2k)!}\,I + \sum_k \frac{(-i\theta/2)^{2k+1}}{(2k+1)!}\,A
= \cos\frac{\theta}{2}\,I - i\sin\frac{\theta}{2}\,A
$$

この $U$ は、Bloch球を軸 $\hat{n}$ のまわりに角度 $\theta$ だけ回転させる操作に対応します。**1量子ビットゲートはすべてBloch球の回転です。**

| ゲート | 行列 | 回転 |
|---|---|---|
| $R_x(\theta)$ | $e^{-i\theta\sigma_x/2}$ | $x$ 軸まわり $\theta$ |
| $R_z(\theta)$ | $e^{-i\theta\sigma_z/2}$ | $z$ 軸まわり $\theta$ |
| $X$ | $\sigma_x$ | $x$ 軸まわり $\pi$(位相 $i$ を除く) |
| $Z$ | $\sigma_z$ | $z$ 軸まわり $\pi$(同上) |
| $H$ | $\frac{1}{\sqrt2}(\sigma_x + \sigma_z)$ | $(\hat x + \hat z)/\sqrt2$ 軸まわり $\pi$ |

$X = i\,e^{-i\frac{\pi}{2}\sigma_x}$ のように、標準的なゲート行列と回転行列は大域位相だけ異なります。第1章のとおり大域位相は観測できないので、この差は物理的には無視できます。

:::note[$\sigma_z$ の対角性と「時間ゼロのゲート」]
$Z$、$S$、$T$ はすべて $z$ 軸まわりの回転で、対角行列です。実機ではこれらを物理パルスではなく**測定基準の位相のつけ替え(フレーム更新)**として実装できるため、時間を消費しません。

Yuragi-Striderが Z, S, T の既定所要時間を 0 としているのは、この実機の慣行を反映したものです。所要時間 0 の区間では散逸も発生しません。
:::

## 2.4 時間依存ハミルトニアン

$H$ が時間に依存すると、話は一気に難しくなります。素朴に

$$
U(t) \stackrel{?}{=} \exp\!\left(-i\int_0^t H(s)\,ds\right)
$$

としたくなりますが、**これは一般には誤り**です。異なる時刻のハミルトニアン $H(t_1)$ と $H(t_2)$ が可換でない限り成り立ちません。正しい解は時間順序積(Dyson級数)で書かれます。

### 区分定数近似

実用上は、時間を細かい区間に切り、各区間内で $H$ を定数とみなす方法をとります。

$$
U(t) \approx e^{-iH_N \Delta t}\cdots e^{-iH_2 \Delta t}\,e^{-iH_1 \Delta t}
$$

**掛ける順序が重要です。** 時間的に早い区間が右側(先に状態に作用する側)に来ます。

各区間で $H$ をその区間の中点の値 $H_k = H(t_k + \Delta t/2)$ にとると、区間あたりの誤差が $O(\Delta t^3)$ になり、端点の値をとる場合($O(\Delta t^2)$)より1次分よくなります。Yuragi-Striderの `midpoint_piecewise_constant_v1` はこの中点則です。

:::tip[これがモデル全体の設計思想です]
Yuragi-Striderは回路を**時間区間の列**に分解し、各区間内でハミルトニアンを定数として扱います。

```text
回路 → ゲート列 → 時間区間の列 → 各区間で H_k を構成 → 積分
```

Gate-awareモデルでは1つのゲート列(column)または待機区間が1区間に対応します。Pulse-levelモデルでは、連続的な包絡線を中点区分定数近似で区間に分割します。

**区間内でハミルトニアンが定数である**という前提は、第8章で扱うCPTP性の保証にも直結しています。
:::

より高次の近似としてMagnus展開があり、交換子の寄与を系統的に取り込めます。Yuragi-Striderは現在これを使っていませんが、[参考文献](../physics-model/references.md)に原典を挙げてあります。

## 2.5 生成子から見たゲート

ここまでの議論を逆向きに読むと、次の問いが立ちます。

> ゲートのユニタリ行列 $U$ と所要時間 $\tau$ が与えられたとき、$e^{-iH\tau} = U$ を満たす $H$ は何か?

この $H$ を**有効ハミルトニアン**(生成子)と呼びます。理想的な回路モデルではゲートは瞬時の行列演算ですが、**有限の時間 $\tau$ をかけて実行されるものとして扱えば、その間に環境ノイズが作用する**という構図が作れます。これがGate-awareモデルの中心的なアイデアです。

$H = \frac{i}{\tau}\log U$ を計算すればよさそうに見えますが、行列対数は一意ではありません。この問題は第5章で正面から扱います。

## 演習

1. $e^{-i\frac{\theta}{2}\sigma_z}$ を $2\times2$ 行列として書き下し、$\rho \to U\rho U^\dagger$ が $\rho_{01} \to e^{-i\theta}\rho_{01}$ を与えることを示せ。Blochベクトルにとってこれは何を意味するか。

2. $[\sigma_x, \sigma_z] = -2i\sigma_y \ne 0$ を確かめよ。$e^{-i\frac{\pi}{2}\sigma_x}e^{-i\frac{\pi}{2}\sigma_z}$ と $e^{-i\frac{\pi}{2}(\sigma_x+\sigma_z)}$ を計算し、一致しないことを確認せよ。

3. Hadamardゲート $H$ は $H^2 = I$ かつ $H^\dagger = H$ を満たす。この性質から $H$ の固有値が $\pm1$ だけであることを示せ。(第5章の「対合経路」の前提になります。)

4. 🔬 IDEの**回路エディター**で回路をクリアし、q0に X を1つ置く。ツールバーの「シミュレーションを実行」で実行したあと、**状態エクスプローラー**の「理想状態の密度行列」でq0が $|0\rangle\to|1\rangle$ になったことを確認せよ。次に X を削除して RX を置き、ゲートを選択して「角度 θ」へ `3.141592653589793` を入力し、Enterで確定して再実行する。2回の「理想状態の密度行列」が一致することを確かめよ(大域位相は密度行列では消える)。

5. 🔬 IDEの**回路エディター**でq0に X を1つ置いた回路と、Xを H → Z → H に置き換えた等価回路を用意し、それぞれ同じ環境設定で実行せよ。右の**計算パラメーター**→「ゲート時間のデフォルト」で X、H、Z の時間を確認し、**状態エクスプローラー**の「物理時間」と「指標タイムライン」を比較する。Zは時間を消費しない一方、2つのHが加わるため、H → Z → H のほうがノイズを受ける時間が長くなることを確認せよ。
