## 9.1 $4^n$ 個の数を1つにまとめる

シミュレーションの生の出力は密度行列 $\rho(t)$ です。5量子ビットなら $1024$ 個の複素数が各時刻に対して並びます。人間がこれを直接読むのは不可能です。

そこで、意味のあるスカラーに圧縮します。ただし圧縮は必ず情報を捨てます。**どの指標が何を見て、何を見落とすか**を理解することが本章の目的です。

## 9.2 Fidelity — 理想からどれだけずれたか

Fidelityは、ノイズを含む状態 $\rho$ と、同じ回路をノイズなしで実行した理想状態 $\rho_{\text{ideal}}$ の一致度です。

### 純粋状態同士の場合

両方が純粋状態 $|\psi\rangle$、$|\phi\rangle$ なら、単純な重なりの2乗です。

$$
F = \big\lvert\langle\psi|\phi\rangle\big\rvert^2
$$

$F = 1$ が完全一致、$F = 0$ が直交(完全に別の状態)です。

### 片方が純粋なら

理想状態が純粋 $\rho_{\text{ideal}} = |\phi\rangle\langle\phi|$ で、$\rho$ が混合の場合、次の簡約形が使えます。

$$
F = \langle\phi|\rho|\phi\rangle = \operatorname{Tr}\!\big(\rho\,\rho_{\text{ideal}}\big)
$$

これは「理想状態を測ったときに、それが得られる確率」そのものです。直感的で、計算も行列の積とトレースだけなので軽量です。

### 一般の場合 — Uhlmann忠実度

両方が混合状態の場合、$\operatorname{Tr}(\rho\sigma)$ は使えません。$\rho = \sigma = I/2$ のとき $\operatorname{Tr}(\rho\sigma) = 1/2$ となり、**同一の状態なのに $F \ne 1$** になってしまうからです。

正しい一般化は**Uhlmann忠実度**です。

$$
\boxed{\
F(\rho,\sigma) = \left(
\operatorname{Tr}\sqrt{\sqrt{\rho}\;\sigma\;\sqrt{\rho}}
\right)^{2}
\ }
$$

行列の平方根が2重に入った、見た目の重い式です。しかし次の望ましい性質をすべて満たします。

| 性質 | 内容 |
|---|---|
| 範囲 | $0 \le F \le 1$ |
| 同一性 | $F(\rho,\rho) = 1$(トレース形と違い、混合状態でも成立) |
| 対称性 | $F(\rho,\sigma) = F(\sigma,\rho)$(式の見た目に反して成り立つ) |
| ユニタリ不変性 | $F(U\rho U^\dagger, U\sigma U^\dagger) = F(\rho,\sigma)$ |
| 単調性 | 任意のCPTP写像 $\mathcal{E}$ について $F(\mathcal{E}\rho,\mathcal{E}\sigma) \ge F(\rho,\sigma)$ |

最後の**単調性**は特に重要です。「どんな物理操作をしても、2つの状態はより見分けにくくなることはあっても、見分けやすくなることはない」という主張で、情報が勝手に増えないことを保証します。

$\sigma = |\phi\rangle\langle\phi|$(純粋)を代入すると、$\sqrt{\sigma} = \sigma$ かつ $\sigma\rho\sigma = \langle\phi|\rho|\phi\rangle\,\sigma$ なので、前節の簡約形に戻ります。

:::note[実装が分岐する理由]
Uhlmann忠実度は行列平方根を2回計算するため、トレース形より格段に重い計算です。そこでYuragi-Striderは、**理想状態の純度が $1$ から $10^{-8}$ 以内なら簡約形、そうでなければUhlmann形**という分岐を使います。

理想状態が混合になるのは、回路が**射影測定を含む**場合です。測定は非選択的な射影チャネルとして実装されており、結果を捨てるため状態が混合になります。したがって測定を含む回路は自動的にUhlmann経路を通ります。
:::

:::warning[Fidelityの定義には2つの流儀があります]
文献によっては、上式の平方根 $\sqrt{F}$ のほうを "fidelity" と呼びます。値が違うので、他のツールと比較するときは必ずどちらの規約かを確認してください。Yuragi-Striderは**2乗した側**($F = (\operatorname{Tr}\sqrt{\cdots})^2$)を使います。
:::

## 9.3 Purity — どれだけ混ざったか

$$
P = \operatorname{Tr}(\rho^2)
$$

第1章で見たとおり、$d$ 次元系で $1/d \le P \le 1$ です。

FidelityとPurityは**別のことを測っています**。

| | Fidelity | Purity |
|---|---|---|
| 参照が必要か | 必要(理想状態) | 不要 |
| 測るもの | 目標からのずれ | 状態の混ざり具合 |
| ユニタリ誤差 | 検出する | **検出しない** |

コヒーレントな誤差(たとえば回転角がわずかに違うゲート)は、状態を純粋なまま別の場所へ動かします。この場合 **Purityは 1 のままで、Fidelityだけが下がります**。逆にデコヒーレンスは両方を下げます。

**2つの指標を並べて見ることで、誤差の種類が推定できます。**

| Fidelity | Purity | 推定される原因 |
|---|---|---|
| 低い | 高い | コヒーレントな制御誤差 |
| 低い | 低い | デコヒーレンス |
| 高い | 高い | 良好 |

### 線形エントロピーとBloch半径

純度は次の量とも直結しています。

$$
S_L = 1 - \operatorname{Tr}(\rho^2)
\qquad(\text{線形エントロピー})
$$

1量子ビットではBloch半径と $P = (1 + \lVert\vec r\rVert^2)/2$ の関係にあり、**純度はBloch球の中心からの距離そのもの**です。von Neumannエントロピー $S = -\operatorname{Tr}(\rho\log\rho)$ より計算が軽く、対数の特異点も避けられます。

## 9.4 トレース距離

2つの状態がどれだけ「区別できるか」を直接測る量です。

$$
D(\rho,\sigma) = \frac{1}{2}\operatorname{Tr}\big\lvert\rho-\sigma\big\rvert
= \frac{1}{2}\sum_j \lvert\lambda_j\rvert
$$

($\lambda_j$ は $\rho-\sigma$ の固有値。)

トレース距離には明快な操作的意味があります。**1回の最適な測定で2つの状態を正しく識別できる確率は $\frac{1}{2}(1 + D)$ です。** $D = 0$ なら区別不可能(当てずっぽうの 50%)、$D = 1$ なら完全に識別可能です。

FidelityとトレースDistanceは**Fuchs–van de Graaf不等式**で結ばれます。

$$
1 - \sqrt{F} \ \le\ D \ \le\ \sqrt{1 - F}
$$

一方が 1(または 0)に近ければ他方も対応する極限に近い、という意味で、両者は同等の情報を持ちます。用途によって使い分けます。

- **Fidelity**: 直感的、ゲート性能の慣用的な指標
- **トレース距離**: 距離の公理(三角不等式)を満たすので、誤差の積み上げ評価に向く

Yuragi-Striderの検証では、RK4とCPTPの経路比較などにトレース距離が使われています。

## 9.5 出力確率

計算基底での測定確率は、密度行列の対角成分そのものです(第1章 1.3節)。

$$
P(k) = \rho_{kk}
$$

**この量は非対角成分をまったく見ません。** したがって、コヒーレンスが完全に失われていても出力確率だけは正しく見えることがあります。

たとえばBell状態 $\frac{1}{\sqrt2}(|00\rangle+|11\rangle)$ と、古典的な混合 $\frac{1}{2}(|00\rangle\langle00| + |11\rangle\langle11|)$ は、出力確率が完全に同一です。前者はエンタングルしており、後者は単なる相関です。

:::tip[出力確率だけを見てはいけない]
実機の量子計算機では、多数回の測定から出力確率のヒストグラムを得ます。それだけでは量子性の有無が分かりません。密度行列を直接見られることは**シミュレーターの特権**であり、学習にとって最も価値のある部分です。

Yuragi-StriderのDensity Matrix Viewerで非対角成分を確認する習慣をつけてください。
:::

## 9.6 有効時間 — 発見的な指標

Fidelityが指定したしきい値を初めて下回る時刻です。

$$
t_{\text{eff}} = \min\left\{\, t_i \;\middle|\; F(t_i) < F_{\text{threshold}} \,\right\}
$$

既定のしきい値は 0.9 です。最後まで下回らなかった場合は最終時刻が返されます。

:::warning[これは標準的な物理量ではありません]
「回路が実用的に機能しつづける時間」を直感的に示すためにYuragi-Striderが定義した指標です。しきい値 0.9 に物理的な導出はなく、**学習用に選ばれた値**です。

さらに次の性質に注意してください。

- サンプル時刻の離散性に依存する(細かくサンプルすれば値が変わる)
- しきい値を跨ぐのが1回とは限らない(振動する場合、最初の交差しか見ない)
- 回路によって意味が変わる

論文で引用できるような量ではありません。UIで「使用可能時間」と表示されるのは、あくまで初学者向けの言い換えです。
:::

$T_1$ や $T_2$ のような**物理的に定義された時間**と、この $t_{\text{eff}}$ のような**発見的な指標**を混同しないことが重要です。

## 9.7 初学者向けの言い換え

UIでは次の対応で表示されます。

| 内部の量 | 表示 |
|---|---|
| Fidelity | 有効性 |
| Purity | 安定性 |
| Effective time | 使用可能時間 |

言い換えは理解の入口として有用ですが、正確さとは引き換えです。本章まで読んだなら、内部の量の名前で考えることをおすすめします。

## 9.8 漏れの定量化

qutritモデルでは、計算部分空間 $\{|0\rangle, |1\rangle\}$ の外へ出た分を測ります。

$$
L = \operatorname{Tr}\big(\rho\,\Pi_{\text{leak}}\big),
\qquad
\Pi_{\text{leak}} = |2\rangle\langle2|
$$

第6章で見たDRAGの効果は、この量で評価されました($0.261 \to 0.023$)。

漏れが特別扱いされるのは、それが**計算空間の外**で起きるからです。$|0\rangle$ と $|1\rangle$ だけを見る通常の誤り訂正符号では検出できず、Fidelityの低下としてしか現れません。原因の切り分けには漏れを別に測る必要があります。

## 9.9 指標の選び方

まとめとして、何を知りたいときにどれを見るかを整理します。

| 知りたいこと | 見る指標 |
|---|---|
| 目標の状態が作れたか | Fidelity |
| デコヒーレンスの進行 | Purity |
| 誤差の種類(コヒーレント / 非コヒーレント) | Fidelity と Purity の組 |
| 測定して何が出るか | 出力確率 |
| 量子性が残っているか | 密度行列の非対角成分 |
| 計算空間から出ていないか | 漏れ |
| 数値解が信頼できるか | 診断(最小固有値、トレース誤差) |

**最後の行を忘れないでください。** 物理的な指標がどれほど良く見えても、数値解が非物理的なら意味がありません。第7章・第8章で扱った診断は、他のすべての指標の前提です。

## 演習

1. $\rho = \sigma = I/2$ のとき、$\operatorname{Tr}(\rho\sigma)$ と Uhlmann忠実度をそれぞれ計算し、後者だけが 1 になることを確かめよ。

2. $\sigma$ が純粋状態のとき、Uhlmann忠実度が $\langle\phi|\rho|\phi\rangle$ に帰着することを示せ。

3. $\rho = \operatorname{diag}(1,0)$、$\sigma = \operatorname{diag}(1-p, p)$ について $F$ と $D$ を求め、Fuchs–van de Graaf不等式を確かめよ。

4. Bell状態と、対応する古典混合状態のBloch表現(2量子ビットなので相関行列)を比較し、出力確率が同じで密度行列が違うことを確認せよ。

5. 🔬 **Pulse 回路スタジオ**でq0のX Pulseを選び、Gaussian波形・回転角 $\pi$ のまま「DRAG β [μs]」を `0` にして保存する。**Pulseラボ**で「準位数」を「3準位 qutrit(漏れ準位あり)」、「環境入力」を「Lindblad率を直接指定」とし、5つの率をすべて0にして実行せよ。「目標状態との重なり」が1未満でも「最終純度」がほぼ1になる条件を探し、リーケージというコヒーレント誤差が9.3節の表と整合するか確認せよ。

6. 🔬 同じPulseのまま「環境入力」を「物理パラメータ」に戻し、デバイス品質・温度・磁束ノイズを既定値で実行せよ。設問5の結果と「目標状態との重なり」「最終純度」を比較し、散逸を加えると純度も下がることを確かめよ。

7. 🔬 Gate-awareの同じ回路・環境に対し、IDEの右の**計算パラメーター**の「忠実度のしきい値」を `0.9` と `0.99` にして2回実行せよ。各結果について**状態エクスプローラー**の「指標タイムライン」で「有効操作時間」を読み、しきい値を高くするとどう変わるか確認せよ。

## おわりに

全9章を通して、環境パラメータの入力から指標の出力まで、Yuragi-Striderの計算経路を理論の側から辿ってきました。

最後に、このシミュレーターを使ううえで最も大切なことを繰り返します。

:::warning[Yuragi-Striderは校正済みのハードウェアモデルではありません]
実装しているデバイスプロファイルは一般的なトランズモンを模した**学習用**のものであり、特定の実機を定量的に再現することを目的としていません。

- ゲートの既定所要時間、デバイス品質の写像、磁束ノイズの線形写像、有効時間のしきい値は、いずれも**学習用に選ばれた値**であり物理的な導出を持ちません
- Born-Markov近似が全入力範囲で成立する保証はありません
- RWAの破れ、非マルコフ性、クロストーク、読み出し誤差は表現されません

境界の全体像は[前提と適用範囲](../physics-model/assumuptions.md)と[制限事項](../limitations/current-limitations.md)にまとめてあります。
:::

一方で、**このシミュレーターが何をどこまで検証したか**は完全に公開されています。解析解との比較、独立実装間の一致、QuTiPとの突き合わせ、そのすべての数値が[妥当性検証](../physics-model/validations/index.md)に記録されています。

理論から予測を立て、シミュレーターで確かめ、検証記録と突き合わせる。この3点の往復こそが、本セクションが提供したかった学習環境です。
