# 今後の予定

[現在の制限事項](./current-limitations.md)のうち、解消に着手する予定があるものを優先順に並べます。各項目で実装済みと明記した範囲を除き、ここに書かれているのは**まだ実装されていない事項**であり、現時点の機能ではありません。

## 1. 実機比較のやり直し(最優先)

[実機比較](/docs/physics-model/validations/hardware-comparison)は形式的な合格判定に至っておらず、主因と推定した読み出し誤差は[実装と数値検証まで完了](/docs/physics-model/validations/readout-error)しています。残っているのは、それによって実機との一致が実際に改善するかの確認です。

計画は次のとおりです。

| 項目 | 内容 | 前回からの変更点 |
|---|---|---|
| 合格基準 | 測定前に凍結する | 前回は事前登録が実行前に確定していなかった(手続き上の不適合) |
| バックエンド | `ibm_kingston` に加えて `ibm_fez`・`ibm_marrakesh` | 前回は単一機・単一ジョブ中心 |
| 読み出しの扱い | 実機側へ補正を掛ける従来方式と、モデル側へ付加する方式の**両方**でカバー率を算出する | 前回はモデル側に読み出し誤差が存在しなかった |
| 見たいもの | 特定の1台の定量再現ではなく、**モデルとのズレが実機ごとにどう分布するか** | — |

最後の行が目的です。特定の1台に数値を合わせ込めても別の実機ではまたズレるはずで、そのズレ方の分布こそが本来見るべき量だと考えています。

準備作業として、アプリ内には $\lvert1\rangle$ の減衰を時間掃引し、
`単一指数 + 観測床` へ適合するT1専用スイープを追加済みです。これは保存済みデータや
将来の実機データと同じ形の減衰モデルを確認するための機能ですが、実機再測定そのものを
完了したことは意味しません。

同じく、明示的な離調を与えるRamsey専用スイープと、指数包絡・ガウス包絡のAICc比較も
追加済みです。現段階では時間一定の離調とマルコフ的散逸を扱うシミュレーション内解析であり、
実機で見られた周波数ドリフトや非マルコフ減衰を再現したものではありません。

:::note[実施時期]
IBM Quantumの無料実行枠を先の検証で使い切っているため、枠が回復し次第の実施になります。
:::

## 2. 読み出し過程の物理的なモデル化

現在の読み出し誤差は**アフィン2点近似**であり、読み出し共振器・IQ平面上の判別過程・測定中の $T_1$ 緩和は、すべて $p_{10}$ と $p_{01}$ の2つの数値へ畳み込まれています([制限事項](./current-limitations.md#読み出し誤差について))。

共振器を含めた測定の時間発展として陽にモデル化することで、これらを個別の物理過程として扱えるようにする予定です。

## 3. 扱える量子ビット数の拡張

現在の上限は[規模の上限](./current-limitations.md#規模の上限)のとおり、ノイズを含む密度行列計算で8量子ビット、Pulse-levelのトランズモン・ネットワークで4台です。密度行列は次元が指数的に増えるため、この拡張には計算基盤側の設計変更が必要になります。

## 4. より実機に近い制御モデル

次の依存順で進めます。

1. **量子ビット別 $T_1$・$T_\phi$・読み出し誤差** — 実装済み。Gate-aware回路と
   結合トランズモン・ネットワークで、共通値を局所校正値により上書きできます
2. **ジョブ間ドリフトと時間変動** — 未実装。まず1ジョブ内では一定の準静的ドリフトを
   導入し、その後にジョブ内時間変動へ進みます
3. **意図しない相互作用** — 未実装。検証しやすい静的ZZ結合、駆動クロストーク、
   制御線の伝達関数の順に追加します

可変結合器の陽なモデルは、上記3段階の後に検討します。

## 5. 攻撃シミュレーションモード

desktop／development向けの共通基盤と自由モードの画面は実装済みです。宣言した仮想サービス条件の下で、環境作成・回路送信・明示的な待機・結果照会・破棄まで操作できます。

最初のReset漏洩課題は準備中です。課題preset・採点器・被害者の共通Programへの接続が残っており、課題の完成や実機での攻撃実証を意味しません。現行profileの前提、近似、公開運用との境界は[攻撃シミュレーターの前提と限界](./attack-simulator.md)を参照してください。

## 位置づけ

上記1〜4は、Yuragi-Striderを教育用シミュレーターとしてだけでなく、**量子デバイスや開放量子系そのものを調べる道具**として使えるところまで持っていくための項目です。

現在どこまで検証されているかは[妥当性検証](/docs/physics-model/validations/)を、何を扱わないと明示しているかは[現在の制限事項](./current-limitations.md)を参照してください。
