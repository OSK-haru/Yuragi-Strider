# 前提と適用範囲

Yuragi-Striderの物理モデルが置いている前提と、その結果として生じる適用範囲の境界を示します。ここに書かれていない条件下での結果は、物理的に意味を持たない場合があります。

## 中心となる前提

### マルコフ性(記憶のない環境)

環境との相互作用はGKSL型のマルコフ的マスター方程式で記述されます。環境が過去の状態を記憶して系に影響を返す**非マルコフ的なダイナミクスは扱いません**。

唯一の例外はPulse-levelモデルの**準静的ノイズ**で、これはショットごとに固定された離調のアンサンブル平均として実装されており、厳密な非マルコフ性の記述ではありません。

### 回転波近似(RWA)

Pulse-levelモデルはすべて回転系上でRWAを適用しています。搬送波を実験室系で陽に積分することはしません。

### 準位の切り詰め

| モデル | 準位数 | 切り詰めの影響 |
|---|---|---|
| Gate-aware | 2(量子ビットあたり) | 漏れ(leakage)を表現しない |
| Pulse Baseline A | 2 | 同上 |
| Pulse Extension B | 3(qutrit) | 第3準位への漏れを表現できる |
| Coupled transmon network | $L^N$($L\in\{2,3\}$、$N\le4$) | 同上(各トランズモン) |

3準位モデルであっても、漏れが大きい領域(たとえば漏れ率が数十%に達する強駆動)では切り詰め自体が妥当でなくなります。

### 弱結合

系と環境の結合は弱く、環境は系の影響を受けないものとして扱います。

### 測定と読み出しの分離

`MEASURE` による射影(重ね合わせを壊す非選択的測定)は**理想的**であるとし、読み出し装置の誤りとは別に扱います。

読み出し誤差を有効にした場合、それは**アフィン2点近似**として終端の観測確率にのみ適用されます。読み出し共振器、IQ平面上の判別過程、測定中の $T_1$ 緩和は陽にモデル化せず、$p_{10}$・$p_{01}$ という2つの校正値へ畳み込まれます。

$$
p_{10} = P(\text{観測}1 \mid \text{準備}0),
\qquad
p_{01} = P(\text{観測}0 \mid \text{準備}1)
$$

この前提の帰結として、読み出し誤差は密度行列・Fidelity・Purityを変化させません。装置の性質であって状態の性質ではないためです。

## 校正されたハードウェアモデルではない

これは最も重要な適用範囲の境界です。

実装されているデバイスプロファイルは、コード上でも「Generic transmon-inspired profile, **not a calibrated hardware model**」と明記されています。次のことは目的としていません。

- 特定の実機の定量的な再現
- パルス形状・ゲート誤差・周波数ドリフト・SPAM誤差の分離
- 実験値の予測

実機との比較は探索的に実施していますが、形式的な合格判定は確立していません。詳細は[実機比較](./validations/hardware-comparison.md)を参照してください。

## 実装上の制限

### 未実装の機能

| 項目 | 状態 |
|---|---|
| モンテカルロ軌跡(quantum trajectory) | **未実装**。API上は `trajectory_available: false` を返す |
| 有効ハミルトニアン / no-jump発展 | 未実装 |
| 実機校正に基づく予測 | 未実装 |
| クロストーク・伝達関数 | 未実装 |
| Gate-awareモデルとPulse-levelモデルの連携 | 未実装(Pulse Labは単発パルスのみで、回路を消費しない) |

### 規模の上限

```text
最大論理量子ビット数            : 18
密度行列(ノイズあり)の上限      : 8
状態ベクトル経路の上限          : 18
古典分岐の上限                  : 4096
```

ノイズを含む密度行列計算は8量子ビットまでです。それを超える場合、環境が理想的(3つのレートがすべて $10^{-15}$ 以下)かつ測定を含まない回路に限り、状態ベクトル経路で実行されます。この条件を満たさない9量子ビット以上の要求は、ブロッキングエラーとして拒否されます。

なお、5量子ビットを超える理想環境・測定なしの回路は、8量子ビット以下であっても状態ベクトル経路に自動的に切り替わります。また、ノイズを含む6量子ビット以上の回路では明示的CPTP経路を選べません(RK4のみ)。

### CPTP性の扱い

明示的CPTP経路は、各時間区間内でハミルトニアンと散逸子を定数とみなした写像に対してのみCPTP性が保証されます。時間依存性は中点区分定数近似(`midpoint_piecewise_constant_v1`)であり、**連続的な時間依存問題に対する厳密なCPTP積分ではありません**。

RK4経路は有限ステップでCPTP性が保証されません。ステップが粗い場合、密度行列の固有値が負に振れることがあります。実装は各ステップ後にHermite化とトレース正規化による整形(cleanup)を行いますが、これは数値誤差の吸収であり、発散したRK4を救済するものではありません。この事実は[時間発展の検証](./validations/propagation.md)で数値的に確認されています。

## 前提が破れる典型的な条件

- ステップが粗すぎる場合(特に非調和性が大きいqutritの高速パルス)
- 漏れが大きい強駆動領域
- 実機の定量再現を期待した場合
