# 入力モデルの検証

環境パラメータから物理レートへの写像([入力とパラメータ](../input_and_parameters.md))が正しいかを検証します。各項目を「数式 → 説明 → 検査方法 → 検査結果」の順に記述し、検査方法で挙げたケースには**すべて対応する結果を掲載**します。

---

## 1. 熱占有数と詳細釣り合い

### 数式

温度 $T$、量子ビット周波数 $f_q$ に対する熱占有数と、そこから構成されるレートは次式です。

$$
n_{\text{th}} = \frac{1}{\exp\!\left(\dfrac{h f_q}{k_B T}\right) - 1},
\qquad
\gamma_\downarrow = \gamma_0\left(1 + n_{\text{th}}\right),
\qquad
\gamma_\uparrow = \gamma_0\, n_{\text{th}}
$$

$\gamma_0 = 1/T_1$ はゼロ温度での緩和レート、$\gamma_\downarrow$ は下向き遷移(緩和)、$\gamma_\uparrow$ は上向き遷移(熱励起)のレートです。

この構成が正しければ、詳細釣り合いが恒等的に成立します。

$$
\frac{\gamma_\uparrow}{\gamma_\downarrow} = \exp\!\left(-\frac{h f_q}{k_B T}\right)
$$

検査する誤差は次の2つです。

$$
E_{n} = \left| n_{\text{th}}^{\text{実装}} - n_{\text{th}}^{\text{参照式}} \right|,
\qquad
E_{\text{DB}} = \left| \frac{\gamma_\uparrow}{\gamma_\downarrow} - \exp\!\left(-\frac{h f_q}{k_B T}\right) \right|
$$

### 説明

有限温度の開放系では、下向き遷移だけでなく熱励起による上向き遷移が存在します。両者の比が Boltzmann 因子に一致することが、平衡状態を正しく再現するための必要条件です。

この検査は、実装が計算する $n_{\text{th}}$ が独立に書き下したBose-Einstein式と一致すること、および実装が構成する2つのレートの比が詳細釣り合いを満たすことを確認します。あわせて、極低温で指数関数がオーバーフローしないための数値処理が意図どおり働くかも確認します。

### 検査方法

**固定した入力**(周波数・温度を掃引するケースでは、掃引する量のみを変えます)

| 入力 | 値 | 意味 |
|---|---|---|
| $T_1$(0 K) | 100 μs | `t1_zero_temperature_us` |
| 量子ビット周波数 $f_q$ | 5.0 GHz | 周波数掃引以外での既定値 |
| ゼロ温度レート $\gamma_0$ | 0.01 μs⁻¹ | 上記 $T_1$ から決まる従属量 |

**比較の対応**

| 項目 | Yuragi-Strider側 | 参照側 | 対応 |
|---|---|---|---|
| 熱占有数 | 環境設定からレートを計算する実装が返す $n_{\text{th}}$ | 検証スクリプト内で独立に書いたBose-Einstein式 | 同じ $T$・$f_q$ を与える |
| レート比 | 実装が構成した $\gamma_\uparrow / \gamma_\downarrow$ | Boltzmann 因子 $e^{-hf_q/k_BT}$ | 実装が返したレートのみから比を取る |
| 崩壊演算子 | 実装が生成した演算子の集合 | 係数 $\sqrt{\gamma_\downarrow}$、$\sqrt{\gamma_\uparrow}$ を手で構成した行列 | 演算子の個数と係数を照合 |

**検査ケース**(全8種、記録は25行)

| ケース | 与える入力 | 何を検査するか |
|---|---|---|
| 1 | $T = 0$、5 GHz | 熱励起が厳密に消えること |
| 2 | $T = 0$、1 / 5 / 10 GHz | ゼロ温度では周波数によらず熱励起が消えること |
| 3 | $T = 10^{-9}$ / $10^{-6}$ / $0.001$ mK | 極低温で指数がオーバーフローせず 0 に落ちること |
| 4 | 0 / 1 / 10 / 20 / 100 / 1000 mK(5 GHz) | 解析式との一致と、温度に対する単調増加 |
| 5 | 1 / 3 / 5 / 10 GHz(100 mK) | 解析式との一致と、周波数に対する単調減少 |
| 6 | (20 mK, 10 GHz) / (50 mK, 5 GHz) / (100 mK, 1 GHz) / (200 mK, 5 GHz) | 詳細釣り合いの成立 |
| 7 | $T = 0$、1量子ビット | 生成される崩壊演算子の個数と係数 |
| 8 | $T = 0$ の物理入力 と 理想参照モード | 「物理的に低温」と「レートを 0 にする設定」が別物であること |

内訳は 1 + 3 + 3 + 6 + 4 + 4 + 1 + 1 = 23 行、これに単調性の判定 2 行(ケース4・5)を加えて 25 行です。対応する自動テストは10件あります。

:::note[理想参照モードとは]
すべてのレートを 0 に固定し、ノイズのない理想的な動作を再現する入力オプションです([入力とパラメータ](../input_and_parameters.md)を参照)。ケース8は、これが「温度を 0 にすること」とは異なることを確認します。物理的に $T=0$ でも緩和 $\gamma_\downarrow$ は残るためです。
:::

数値処理の分岐($T \le 0$ なら 0 を返す、指数部が 700 を超えたら 0 を返す、それ以外は桁落ちを避ける計算を使う)も監査対象に含めます。

## 2. 有限温度における平衡

### 数式

ハミルトニアンを 0、位相緩和を 0 とした緩和過程では、励起状態の占有確率が解析的に解けます。

$$
P_1(t) = P_1^{\text{eq}} + \left(P_1(0) - P_1^{\text{eq}}\right)e^{-(\gamma_\downarrow + \gamma_\uparrow)t},
\qquad
P_1^{\text{eq}} = \frac{\gamma_\uparrow}{\gamma_\downarrow + \gamma_\uparrow}
$$

検査する誤差は、軌跡の最大絶対誤差と二乗平均平方根誤差です。

$$
E_{\max} = \max_t \left| P_1^{\text{sim}}(t) - P_1^{\text{解析}}(t) \right|,
\qquad
E_{\text{RMSE}} = \sqrt{\frac{1}{N}\sum_t \left(P_1^{\text{sim}}(t) - P_1^{\text{解析}}(t)\right)^2}
$$

### 説明

平衡値 $P_1^{\text{eq}}$ は初期状態に依存しません。したがって $\lvert0\rangle$、$\lvert1\rangle$、最大混合状態 $I/2$ のどれから出発しても、同じ値へ収束しなければなりません。

この検査は、緩和の時定数 $1/(\gamma_\downarrow + \gamma_\uparrow)$ と到達点 $P_1^{\text{eq}}$ の両方を同時に確かめます。前者は時間発展の正しさ、後者は温度からレートへの写像の正しさに対応します。

### 検査方法

**2つの層で6ケース**を実行します。各ケースは3つの初期状態($\lvert0\rangle$、$\lvert1\rangle$、$I/2$)で実行するため、軌跡の総数は 18 本です。

| 層 | 与える入力 | ケース数 | ねらい |
|---|---|---|---|
| レート直接指定 | $\gamma_\downarrow$、$\gamma_\uparrow$ を数値で直接与える | 3 | 入力写像を介さず、時間発展だけを検査する |
| 物理入力経由 | 温度 50 / 100 / 200 mK、5 GHz、$T_1$(0 K) 100 μs | 3 | 温度からレートへの写像を含めて検査する |

2層に分けるのは、誤差が出たときに**時間発展の問題か入力写像の問題か**を切り分けるためです。

**比較の対応**

| 項目 | Yuragi-Strider側 | 参照側 | 対応 |
|---|---|---|---|
| 初期状態 | $\lvert0\rangle$ / $\lvert1\rangle$ / $I/2$ | 同じ $P_1(0)$ を解析式に代入 | 各ケースで3本とも比較 |
| ハミルトニアン | 0 | 0 | 純粋な緩和過程 |
| レート | 上表のとおり | 実装が返した $\gamma_\downarrow$、$\gamma_\uparrow$ を解析式に代入 | 参照側は実装のレートを使い、解き方だけが独立 |
| 比較量 | 各時刻の $P_1$ | $P_1(t)$ の解析式 | 同一時刻の値どうし |

**許容誤差**

| 検査する量 | 許容誤差 |
|---|---|
| $P_1$ の最大絶対誤差 $E_{\max}$ | $10^{-6}$ |
| $P_1$ の二乗平均平方根誤差 $E_{\text{RMSE}}$ | $10^{-7}$ |
| 軌跡から再推定したレートの相対誤差 | $10^{-4}$ |
| 初期状態を変えたときの最終 $P_1$ の差 | $10^{-5}$ |
| トレース誤差 $\lvert\operatorname{Tr}\rho - 1\rvert$ | $10^{-10}$ |
| Hermite性の破れ | $10^{-10}$ |
| 密度行列の最小固有値 | $\ge -10^{-10}$ |
| 内部ステップを細かくしたときの差 | $10^{-7}$ |

補助的な検査として、軌跡から指数フィットでレートを再推定して入力レートと比べ、内部ステップを 0.5 / 0.25 / 0.125 μs と細かくしても結果が変わらないことを確認します。

## 3. レート変数の命名規約

### 数式

崩壊演算子の係数は、次の3つに固定されています。

$$
L_\downarrow = \sqrt{\gamma_\downarrow}\,\sigma^-,
\qquad
L_\uparrow = \sqrt{\gamma_\uparrow}\,\sigma^+,
\qquad
L_\phi = \sqrt{\frac{\gamma_\phi}{2}}\,\sigma_z
$$

population緩和の合計レート $\gamma_{\text{pop}} = \gamma_\downarrow + \gamma_\uparrow$ は実効 $T_1$ の算出にのみ用い、崩壊演算子の係数としては**使いません**。

$$
T_1^{\text{eff}} = \frac{1}{\gamma_{\text{pop}}}
$$

### 説明

$\gamma_\downarrow$ と $\gamma_{\text{pop}}$ は有限温度では異なる量です。これを取り違えると、崩壊演算子の強さが $\sqrt{1 + 2n_{\text{th}}}$ 倍ずれます。低温では両者の差が小さいため、目視では発見しにくい種類の誤りです。

この項目は、正しい名前と互換用に残された名前の対応関係が、計算コア・API・UIのすべての層で一貫していることを確認します。

### 検査方法

自動テストで次の3点を検査します。

| 検査項目 | 判定基準 |
|---|---|
| 崩壊演算子の係数 | 上記3式のとおりであること |
| $\gamma_{\text{pop}}$ の用途 | 崩壊演算子の係数として使われていないこと |
| 互換名 `gamma1_per_us` | $\gamma_\downarrow$ の読み取り専用の別名であり、$\gamma_{\text{pop}}$ ではないこと |

対象テスト: `tests/test_rate_variable_naming_refactor.py` および API / UI アダプタのテスト。

### 検査結果

**判定: PASS**(3項目すべて、該当テストが通過)

入力は、0 Kでの $T_1$、$T_\phi$、温度、周波数という測定できる量だけで、散逸率はそこから上の式で決まります。この式(熱占有数、詳細釣り合い、有限温度平衡、純粋位相緩和の係数)は上の検証で確かめています。$T_1$ と $T_\phi$ の値そのものは利用者が与える入力で、モデルの予測ではありません。
