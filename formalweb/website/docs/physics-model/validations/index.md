# 妥当性検証

Yuragi-Striderはシミュレーターであり、その出力が物理的に妥当であることは自明ではありません。このセクションは、実装された各モデルが**何と比較され、どの許容誤差のもとで、どのような結果が得られたか**を公開するための記録です。

## 記述形式

すべての検証項目を、次の4つの見出しで統一して記述します。

| 見出し | 内容 |
|---|---|
| 数式 | 検査対象の方程式、比較相手となる参照式、および誤差の定義 |
| 説明 | その式が何を意味し、この検査で何が確かめられるのか |
| 検査方法 | 入力値・条件・許容誤差・比較手順・再現用スクリプト |
| 検査結果 | 実測値、判定、および結果の解釈 |

## 比較検証における入力の対応

独立ソルバー(QuTiP)や実機との突き合わせでは、検査方法の中に**入力の対応表**を置きます。両者に何を入力し、何を計算させ、どの量どうしを比較したのかを1対1で示すためです。

| 列 | 意味 |
|---|---|
| 項目 | 比較の構成要素(初期状態、ハミルトニアン、散逸、時刻列など) |
| Yuragi-Strider側 | 本シミュレーターに与えた入力と、実行させた計算 |
| 参照側 | QuTiPまたは実機に与えた入力と、実行させた計算 |
| 対応 | 両者が同一とみなせる根拠、または意図的に異なる点 |

「意図的に異なる点」を明記するのは、比較の**独立性の度合い**が項目ごとに異なるためです。Yuragi-Striderが構成した行列をそのままQuTiPに渡す比較と、公開リクエスト仕様だけを見てQuTiP側が行列を組み直す比較とでは、検出できる誤りの範囲が違います。

| 独立性 | 内容 | 検出できる誤り | 検出できない誤り |
|---|---|---|---|
| 積分器のみ独立 | Yuragi-Striderの行列をQuTiPへそのまま渡す | 時間積分・ステップ制御の誤り | 行列構成そのものの誤り |
| 行列構成も独立 | 公開仕様からQuTiP側が独立に行列を再構成する | 行列構成の誤り、仕様解釈の食い違い | 両者が共有する物理的前提の誤り |
| 実機との比較 | 実際の量子プロセッサの測定値と比較する | モデル全体と現実のずれ | ずれの原因の切り分け |

## 誤差の指標

密度行列どうしの比較には、次の共通指標を用います($\Delta = \rho^{\mathrm{YS}} - \rho^{\mathrm{ref}}$)。

$$
E_{\max} = \max_{j,k}\left|\Delta_{jk}\right|,
\qquad
E_F = \|\Delta\|_F,
\qquad
D = \frac{1}{2}\sum_i s_i(\Delta)
$$

$E_{\max}$ は最大要素誤差、$E_F$ はFrobenius誤差、$D$ はトレース距離($s_i$ は特異値)です。あわせて、各時刻の状態が密度行列として成立しているかを次の3点で確認します。

$$
\left|\operatorname{Tr}\rho - 1\right|,
\qquad
\left\|\rho - \rho^\dagger\right\|_{\max},
\qquad
\lambda_{\min}(\rho)
$$

## 検証のカテゴリ

| カテゴリ | 対象 | ページ |
|---|---|---|
| 入力モデル | 環境パラメータからレートへの写像、熱平衡 | [入力モデルの検証](./input.md) |
| 時間発展 | RK4・明示的CPTP・状態ベクトルの各ソルバー | [時間発展の検証](./propagation.md) |
| 制御モデル | Gate-aware、Pulse 2準位 / qutrit / 結合ネットワーク | [制御モデルの検証](./control-models.md) |
| 観測モデル | 読み出し誤差の混同行列と、その適用範囲 | [読み出し誤差の検証](./readout-error.md) |
| 実機比較 | 実際の量子プロセッサとの観測量比較 | [実機比較](./hardware-comparison.md) |

観測モデルだけは性格が異なります。他の項目が密度行列そのものを比較するのに対し、読み出し誤差は密度行列を求めた**後**の観測段に作用するため、検証内容も「混同行列の代数」と「適用範囲が状態レベルの量へ漏れていないこと」になります。

## 基本検証の一覧

Lindbladシミュレーターとして最初に確かめるべき7項目と、その結果をまとめます。式・入力・全ケースの数値は各リンク先にあります。

| 確かめること | 検証 | 比較相手 | 代表的な結果 | 判定 |
|---|---|---|---|---|
| 散逸をゼロにすると、理想的な量子ゲートと一致するか | [ゼロ散逸極限](./propagation.md#1-ゼロ散逸極限のユニタリ発展) | 理想ユニタリ(解析) | 8回路で最大要素誤差 $1.1\times10^{-16}$、Fidelity 1 | PASS(8/8) |
| $T=0$ で熱励起率がゼロになるか | [熱占有数と詳細釣り合い](./input.md#1-熱占有数と詳細釣り合い) | Bose–Einstein分布(解析) | $n_{\text{th}}=0$、$\gamma_\uparrow=0$(厳密)。詳細釣り合いの誤差 $\le 5.6\times10^{-17}$ | PASS(8/8) |
| $\lvert1\rangle$ の占有確率が指数関数で減衰するか | [励起状態の指数減衰](./propagation.md#2-励起状態の指数減衰) | $e^{-\gamma_\downarrow t}$(解析) | 最大誤差 $2.0\times10^{-8}$ | PASS |
| 純粋位相緩和だけのとき、占有確率は変わらず非対角成分だけが減衰するか | [純位相緩和](./propagation.md#3-純位相緩和) | $e^{-\gamma_\phi t}$(解析) | 最大誤差 $1.0\times10^{-8}$。誤った係数 $\sqrt{\gamma_\phi}$ では誤差 0.119 となり、取り違えを判別できる | PASS |
| 有限温度・長時間で熱平衡状態へ近づくか | [有限温度における平衡](./input.md#2-有限温度における平衡) | $P_1^{\text{eq}}=\gamma_\uparrow/(\gamma_\downarrow+\gamma_\uparrow)$(解析) | 最大絶対誤差 $1.0\times10^{-8}$ | PASS(6/6) |
| 時間刻みを変えても結果が収束するか | [時間ステップの収束](./propagation.md#4-時間ステップの収束) | 刻みの細分化と解析解 | 最細刻みで最大誤差 $2.5\times10^{-9}$。観測された収束次数 4.02〜4.09(RK4の理論値 4) | PASS |
| QuTiPと同じ条件で一致するか | [Gate-awareモデルとQuTiPの比較](./propagation.md#5-gate-awareモデルとqutipの比較) | QuTiP 5.2.3 `mesolve` | 7ケースで最大要素誤差 $2.1\times10^{-10}$。許容誤差を3桁以上下回る | PASS(7/7) |

## 独立ソルバー

内部実装の正しさを確認するための独立比較には **QuTiP 5.2.3** を使用します。

```text
qutip  == 5.2.3
scipy  == 1.17.1
numpy  == 2.4.4
python == 3.14.4
```

:::info[QuTiPは本番計算に使用しません]
QuTiPは検証専用の依存関係(`requirements-validation.txt`)です。通常のシミュレーション実行には使われません。Yuragi-Striderの計算コアはPython/NumPyとRustによる独自実装です。

この分離により、QuTiPとの比較が「同じコードを2回実行しただけ」にならないことが担保されます。
:::

QuTiP側は原則として `mesolve`(DOP853、`atol = rtol = 1e-12`、`nsteps = 100000`、`normalize_output = false`)で解きます。最大ステップ幅は検証ごとに指定します。

検証実行環境は Windows 11(10.0.26200)です。

## 検証の3つの層

Yuragi-Striderの検証は、性質の異なる3層で構成されます。

### 1. 解析解との比較

厳密解が存在する状況(ゼロ散逸のユニタリ発展、単一の崩壊演算子による指数減衰、純位相緩和、有限温度平衡、共鳴パルスの回転)で、独立に実装した解析式と突き合わせます。

**この層が最も強い保証を与えます。** 実装の誤りが解析解と偶然一致することは考えにくいためです。

### 2. 独立ソルバーとの比較

解析解が存在しない状況(時間依存パルス、多量子ビット回路、DRAG、結合系)では、QuTiPとの数値比較を行います。

同じ物理を独立した実装で解いて一致すれば、両方が同じ誤りを持つ可能性は低くなります。ただし**両者が共有する前提(RWA、マルコフ性、準位の切り詰め)の妥当性は検証されません**。

### 3. 実機との比較

実際の量子プロセッサで測定した観測量と比較します。

この層は現在**形式的な合格判定に至っていません**。詳細は[実機比較](./hardware-comparison.md)を参照してください。

## 機械可読な検証結果

すべての検証結果は、リポジトリの `validation_results/` にJSON/CSV形式で保存されています。本セクションに記載された数値はこれらのファイルに由来します。

各項目には、対応するファイル名と再現用スクリプトを併記しています。

## 検証が保証しないこと

すべての検証を通過しても、次のことは保証されません。

- 特定の実機の定量的な再現
- 使用するレートが実デバイスのレートと一致すること
- Born-Markov近似が全入力範囲で成立すること
- 固定ステップRK4の有限ステップ写像が常にCPTPであること
- 校正済みハードウェア予測器としての利用

これらは[前提と適用範囲](../assumuptions.md)に整理されています。
