# 出力

シミュレーションの結果として得られる量と、その定義を示します。

## 密度行列

各サンプル時刻における密度行列 $\rho(t)$ が主たる出力です。$N$ 量子ビット系では $2^N \times 2^N$ の複素行列になります。

APIレスポンスでは複素数を次の形式で表現します。

```json
{"real": 0.5, "imag": -0.25}
```

## Fidelity(忠実度)

ノイズを含む状態 $\rho$ と、同一回路をノイズなしで実行した理想状態 $\rho_{\text{ideal}}$ の一致度です。

理想状態が純粋な場合(純度が $1$ から $10^{-8}$ 以内)は、次の簡約形を用います。

$$
F = \operatorname{Tr}\!\left(\rho\, \rho_{\text{ideal}}\right)
$$

理想状態が混合状態の場合(測定を含む回路など)は、Uhlmann忠実度を用います。

$$
F = \left(
\operatorname{Tr}\sqrt{
\sqrt{\rho_{\text{ideal}}}\, \rho \, \sqrt{\rho_{\text{ideal}}}
}
\right)^{2}
$$

射影測定は純度を大きく変えるため、測定を含む回路は自動的に後者の分岐を通ります。

## Purity(純度)

$$
P = \operatorname{Tr}\!\left(\rho^2\right)
$$

純粋状態で $1$、$d$ 次元の最大混合状態で $1/d$ をとります。デコヒーレンスの進行を示す指標です。

## 出力確率

計算基底における測定確率です。ビット列のラベルは **q0 が最上位ビット** の規約に従います。

```text
2量子ビットの例: "00", "01", "10", "11"
```

## 量子ビット別のコヒーレンス時間

物理入力モードでは、共通の `t1_max_us`・`tphi_max_us` に加えて、量子ビットごとの
値を `parameters.per_qubit` で指定できます。省略時は従来どおり共通値が全量子ビットへ
適用されます。

```json
{
  "parameters": {
    "t1_max_us": 100.0,
    "tphi_max_us": 100.0,
    "per_qubit": [
      {"t1_max_us": 72.0, "tphi_max_us": 55.0},
      {"t1_max_us": 108.0, "tphi_max_us": 83.0}
    ]
  }
}
```

各値から量子ビットごとに下降・上昇・純位相緩和レートを計算し、それぞれの局所
Lindblad演算子へ適用します。レスポンスの `rates.per_qubit` には使用した局所レートを
量子ビット順に返します。これは既存モデルの「最大コヒーレンス時間」の個別化であり、
`device_quality`、温度、磁束ノイズは現在も共通です。実機の測定済みT1をそのまま使う場合は、
`device_quality = 1` とする必要があります。

Pulse-levelの結合トランズモン・ネットワークでも、物理環境の `environment.per_qubit` に
同じ形式を指定できます。要素数は論理量子ビット数またはトランズモン数と一致しなければ
なりません。

## 読み出し誤差(readout error)

実機の測定は共振器を介した間接測定であり、$\lvert0\rangle$ と $\lvert1\rangle$ の信号分布が完全には分離しません。そのため観測されたビットは、一定の確率で真の状態と食い違います。Yuragi-Striderは、この誤りを**アフィン2点近似**として出力確率に適用できます。

### 数式

量子ビット $k$ について、2つの誤り確率を与えます。

$$
p_{10} = P(\text{観測}1 \mid \text{準備}0),
\qquad
p_{01} = P(\text{観測}0 \mid \text{準備}1)
$$

対応する混同行列(confusion matrix)は列確率行列です。

$$
A^{(k)} =
\begin{pmatrix}
1 - p_{10} & p_{01} \\
p_{10} & 1 - p_{01}
\end{pmatrix}
$$

観測される分布は、各量子ビットの行列のテンソル積を真の分布に作用させたものです。

$$
P^{\text{obs}}(\mathbf{b})
= \sum_{\mathbf{b}'}
\left[\prod_{k} A^{(k)}_{b_k b'_k}\right]
P^{\text{true}}(\mathbf{b}')
$$

実装は $2^n \times 2^n$ の積を陽に構成せず、量子ビットごとに逐次適用します($O(n\,2^n)$)。$A^{(k)}$ は列確率行列なので、適用後も確率の総和は厳密に保存されます。

### 適用される層

読み出し誤差は**観測装置の性質であって、量子状態の性質ではありません**。したがって適用範囲を次のように限定しています。

| 対象 | 読み出し誤差を適用するか |
|---|---|
| 出力確率 | **する** |
| 測定カウント(ショット) | **する**(適用後の分布から標本化) |
| Pulse-levelの占有確率表示 | **する**(観測表示にのみ適用) |
| 密度行列 | しない |
| Fidelity / Purity / 有効時間 | しない |
| 回路途中の `MEASURE` による射影 | しない |

最後の行が要点です。`MEASURE` ゲートには「回路の途中で重ね合わせを壊す射影」と「終端で確率を読み出す観測」の2つの役割がありますが、**前者は装置内部で起きる状態のダイナミクス**であり、読み出し判別の誤りとは別の現象です。したがって中間測定の射影には手を加えません。

この分離により、既存の物理検証(密度行列レベルでの比較)は読み出し誤差の実装によって影響を受けません。

### 指定方法

APIリクエストの `readout_error` フィールドで指定します。**省略時は無効**で、既存の挙動と完全に一致します。

```json
{"readout_error": {"p10": 0.005, "p01": 0.013}}
```

全量子ビットに同じ値を使う場合は上の形式、量子ビットごとに校正値が異なる場合は `per_qubit` を使います。

```json
{
  "readout_error": {
    "per_qubit": [
      {"p10": 0.005, "p01": 0.013},
      {"p10": 0.004, "p01": 0.009}
    ]
  }
}
```

`per_qubit` の要素数は回路の量子ビット数と一致していなければなりません。

Pulse APIでも同じ `readout_error` を指定できます。レスポンスの `readout` には終端時刻の
`true_probabilities` と `observed_probabilities` の両方を返します。Pulse Labの
占有確率表示は、選択中の時刻に同じ混同行列を適用しますが、密度行列・Purity・Fidelity・
リーケージ量は変更しません。3準位モデルでは二値判別の対象を $\lvert0\rangle$ と
$\lvert1\rangle$ に限定し、$\lvert2\rangle$ の確率はそのまま保存します。

### 検査される条件

実行前に次を検査し、違反する要求は拒否されます。

$$
0 \le p_{10} \le 1,
\qquad
0 \le p_{01} \le 1,
\qquad
p_{10} + p_{01} < 1
$$

3つ目は **assignment span** $(1 - p_{10} - p_{01})$ が正であることの要求です。これが0以下の場合、観測が状態の情報を持たない(あるいは反転している)ことになり、読み出しとして意味をなしません。

### 適用範囲

- アフィン2点近似のみです。読み出し中の $T_1$ 緩和、測定誘起遷移、IQ平面上の判別過程は**陽にモデル化していません**。それらの効果は $p_{10}$、$p_{01}$ という2つの数値へ畳み込まれた形でのみ扱われます
- 量子ビット間の相関した読み出し誤差(crosstalk)は扱いません。各量子ビットは独立とします
- 中間測定の読み出し誤差は適用されません(上表のとおり)
- 3準位Pulseモデルの $\lvert2\rangle$ を別の準位へ誤分類するモデルは扱いません

## T1専用スイープと観測床

Gate-awareワークスペースのT1専用スイープは、1量子ビットを $\lvert1\rangle$ に準備し、
制御ゲートを加えずに指定時間まで発展させます。各時刻の密度行列から真の
$P_1(t)=\rho_{11}(t)$ を取り出し、読み出し誤差が有効なら観測変換を適用したうえで、

$$
P_1^{\mathrm{obs}}(t)=A e^{-t/T_1}+B
$$

へ制約付き最小二乗適合します。制約は $A\ge0$、$B\ge0$、$A+B\le1$、$T_1>0$ です。
適合器はSciPyを本番依存にせず、$T_1$ の対数を1次元探索し、各候補で $A$ と $B$ の
制約付き線形最小二乗を解きます。

$B$ は読み出し誤差だけを意味しません。有限温度における平衡励起人口と、
$p_{10}$・$p_{01}$ による読み出しオフセットが合成された**観測床**です。レスポンスは
真の $P_1$、観測 $P_1$、適合値を各点で分けて返し、状態変化と観測変化を混同しないようにします。

APIは `POST /api/analysis/t1-sweep` で、5〜101点、最大10,000 μsまでに制限されています。

## Ramsey専用スイープと包絡比較

Ramseyスイープでは $\lvert+\rangle$ のコヒーレンスをGate-awareソルバーで時間発展させ、
指定した離調 $\Delta f$ のZ回転を適用した後、最後のHに相当する観測確率を計算します。
このモデルではZ回転と位相共変な散逸項が可換なので、状態の減衰と離調位相を分離して
適用できます。

観測値には指数包絡($p=1$)とガウス包絡($p=2$)をそれぞれ適合します。

$$
P_1^{\mathrm{obs}}(t)=B+A
\exp\!\left[-\left(\frac{t}{T_2^*}\right)^p\right]
\cos(2\pi\Delta f\,t+\phi)
$$

各候補について $T_2^*$、$\Delta f$、$\phi$、$A$、$B$、RMSE、$R^2$、AICcを返し、
AICcが最小の候補を選択します。$\Delta$AICcも返すため、「選ばれた」という結論だけでなく、
もう一方の包絡との差の大きさを確認できます。

APIは `POST /api/analysis/ramsey-sweep` で、9〜101点、最大10,000 μs、正の離調を受け付けます。
離調がサンプリングのNyquist周波数以上になる要求は拒否します。

現在の本番環境モデルはマルコフ的な純位相緩和なので、生成データでは原則として指数包絡が
選ばれます。ガウス候補は比較基準として実装されていますが、準静的離調ノイズを時間発展へ
直接加えたことを意味しません。

## 有効時間(effective time)

Fidelityが指定したしきい値を初めて下回る時刻です。

$$
t_{\text{eff}} = \min\left\{\, t_i \;\middle|\; F(t_i) < F_{\text{threshold}} \,\right\}
$$

しきい値を最後まで下回らなかった場合は、最終時刻が返されます。既定のしきい値は **0.9** です。

この量は「回路が実用的に機能しつづける時間」を直感的に示すための指標であり、標準的な物理量ではありません。

## 診断情報

物理量とは別に、数値的な健全性を確認するための診断が返されます。

| 項目 | 内容 |
|---|---|
| `evolution_mode` | 使用された発展モードの識別子 |
| `simulation_backend` | 実行バックエンド(`python_dense` / `rust_dense_preview`) |
| `integration_substeps` | 内部積分ステップ数 |
| `cleanup_applied` | 密度行列の整形が適用されたか |
| `max_trace_error` | トレースの $1$ からのずれの最大値 |
| `backend_fallback_used` | Rustカーネルからのフォールバックが発生したか |

実行表現の選択についても診断が返されます。

| 項目 | 内容 |
|---|---|
| `execution_representation` | `density_matrix` / `statevector` |
| `state_dimension` | $2^n$ |
| `density_matrix_dimension` | $(2^n)^2$ |
| `representation_policy` | `adaptive_representation_v1` |
| `density_matrix_qubit_limit` | ノイズあり密度行列経路の上限(現在 8) |
| `large_density_matrix_execution` | 密度行列経路を6量子ビット以上で実行したときに `true` |
| `evolution_method_fallback` | CPTPからRK4へフォールバックした理由(該当時のみ) |

`large_density_matrix_execution` は、次元 $64\times64$ 以上の密度行列を扱ったことを示す目印です。エラーではありませんが、実行時間とメモリが急増する領域に入ったことを意味します。

明示的CPTP経路では、加えてChoi行列の監査結果が返されます。

| 項目 | 内容 |
|---|---|
| `cptp_guaranteed_by_construction` | 構成上CPTP性が保証されているか |
| 最小Choi固有値 | 完全正値性の指標(許容 $10^{-12}$) |
| 最大TP誤差 | トレース保存性の指標(許容 $10^{-12}$) |
| `cptp_all_maps_passed_audit` | すべての区間写像が監査を通過したか |

Pulse-levelモデルでは、整形前の**生の状態**に対する物理性診断が別途保持されます。

| 項目 | 内容 |
|---|---|
| `raw_trace_error` | 整形前のトレース誤差 |
| `raw_hermiticity_error` | 整形前のHermite性の破れ |
| `raw_minimum_eigenvalue` | 整形前の最小固有値(負なら非物理) |
| `cleanup_correction_norm` | 整形による補正の大きさ |

整形前の値を保持しているのは、整形が数値誤差を隠してしまわないようにするためです。補正が大きい場合はステップが粗すぎることを示します。

## 警告と制限

レスポンスには `warnings` と `limitations` が含まれ、モデルの境界がクライアント側から見えるようになっています。たとえば次のような内容です。

- 5量子ビット以上の条件付き回路でCPTPからRK4へフォールバックした旨
- 古典分岐数が上限で制約されている旨
- Coupled transmon networkで直接レート入力時に全トランズモンが同じレートを共有している旨
- RK4が厳密な有限ステップCPTP積分ではない旨

## 未実装の出力

モンテカルロ軌跡(quantum trajectory)は**未実装**です。APIは `trajectory_available: false` を返します。この枠は、ジャンプ統計の監査が完了するまで予約されています。
